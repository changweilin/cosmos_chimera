# 從角色設定圖到可換裝的 Blender 模型

從使用者指定的角色與素材開始。把來源圖、可編輯模型、比較基準分開管理。若要求盲建，建模期間只看允許的圖；定稿並留存產物後，才開現版模型或截圖比對。以新角色的輪廓、配件和目標用途決定建法。

## 1. 用同一把尺讀圖

標記正、側、背與斜視角，記下哪一側有髮飾、掛包、袖章。將腳底、下巴、肩、腰、胯、膝和踝換算到同一高度座標。側面標出每個部件自己可見的前後邊界，例如背包與袖口重疊時，分別取樣。保留斜視圖作為尚未使用的驗收視角。單張圖隱藏的深度與無資料的一側屬於推估。

同系列角色在同一站姿、正交鏡頭與尺度下對照。從裸頭網格量解剖頭頂和下巴，以赤腳腳底為身高起點。頭身比為「腳底到解剖頭頂 ÷ 下巴到解剖頭頂」。另量頭寬、頭寬占身高比例，並看同尺度正面與側面。帽子、髮髻、鞋底另量外觀輪廓。依角色設計選擇比例，保留刻意的年齡與體型差異。

## 2. 先做能轉身的人體，再裁衣

先建頭、頸、軀幹、骨盆、四肢、手掌與腳，檢查正面、側面、斜背面和無貼圖視圖。確認髖到膝到踝的中心線連續，膝下急折時查看相鄰截面的中心位移；先修關節走向，再調小腿肌肉和鞋形。側影需要獨立的胸廓、足跟、鞋尖與臉部深度。

有合適的網格或建模管線時延用它。適合以截面建構的新部件可用 [loft.py](scripts/loft.py)：在 Blender Python 將本技能的 scripts 目錄加入 sys.path，匯入 loft。傳入物件名、由下到上的截面列、collection 與 material。每列為 (z, 中心 x, 中心 y, x 半徑, y 半徑)，單位取場景單位。輸出封閉、平滑的網格，縱縫共用幾何頂點；側壁 UV 在 V 0.24–0.76，兩端各有平面 UV 島。此原型適合衣筒、靴、背包和髮束。臉、耳廓、蝴蝶結環、開口衣襬依實際結構另建。

可換裝角色保留完整基礎人體；另外建服裝殼、髮型與穿戴配件。手套下有手、靴子下有腳、短褲下有骨盆和腿。需要可見的袖口、領口或簍空飾品時，給內壁與厚度。切換服裝後，檢查露出的皮膚和髮絲有沒有殘留印上去的帽緣、髮夾、背包或褲袋。將可替換套裝收在命名清楚的集合，以同一個控制值同步切換 viewport 與 render。

## 3. 每個懸掛部件先定義固定端

沿實物追蹤「末端 → 固定件 → 承載件 → 人體」：馬尾根鑽進後腦髮量、蝴蝶結的結扣住馬尾、吊飾經繩連背包、杯子經掛環連包帶。耳飾與徽章也要有承載面。先定固定端才拉長自由端；插接式髮根應有一小段截面埋入髮量。以靠近承載表面的射線命中放置扣件，再給接觸厚度。修懸空優先移動根部幾圈和扣件，保留已核准的髮尖、髮量和下垂輪廓。

在完成的網格上驗證兩件事：整個可見部件是否連得回人體，以及指定根部是否確實進入正確的承載件。馬尾中段碰衣領、髮尖碰背包，仍可能有懸空髮根。父子關係、物件原點重合或外框重疊只能提供線索。

[mesh_contacts.py](scripts/mesh_contacts.py) 可在 Blender Python 對封閉、外向法線的實體檢查。它依鬆散網格島建立世界座標 BVH，檢查三角面交會與完整包覆。具體用法見 [接點驗證範例](references/contact-check.md)。對每套服裝切換可見件後重新驗證；若有動畫或變形，在關鍵姿勢重新取得求值後的網格。開口布料、合理間隙、磁浮物件依設計另訂接觸方式。

## 4. 把圖案放回真正的立體表面

深色衣物貼近背景色時，對照原圖保留夾克、褲襠和褲管內的布料像素。隔開腿間、袖口等真實負空間。遇到疑似破洞，同時看原色算圖、灰模與局部射線結果；封閉的網格也能帶有錯誤的貫穿孔。

按照服裝裁片對齊正、側、背稿的領口、側縫、滾邊、口袋、扣件與鞋底。接合線選在顏色與紋路能連續的位置，亮暗可低頻調和，細線需保持單一輪廓。袖筒正對側面鏡頭時，端面要有自己的平面貼圖與內襯。原畫的手遮住袖口時，補內襯並由真正的手遮擋。帽沿、髮帶等環狀紋樣適合直接繞形體鋪設。立體口袋或掛件建好後，把底布上重複的圖案去掉。

## 5. 重開檔案驗收

- 用同尺度輸出角色正面、原畫同側的正側面、另一側、前後斜視與灰模。髮飾、袖口和背包補局部近照。保留原畫與模型同向的並排圖，左右不對稱的設計要表明翻轉方向。
- 在裸身、預設服裝及實際替換服裝下，檢查露膚、關節截面、接點和穿模。抽驗附著區與預期留空區。若是靜態姿勢，驗證記錄明列靜態範圍。
- 儲存可編輯的 .blend、打包貼圖，再從獨立 Blender 程序重開。檢查遺失資源、非流形邊、退化面和多餘鬆散島。合理的衣物開口或蝴蝶結環需按設計判斷。輸出格式、骨架或引擎整合有指定時，另驗交付檔與實際載入路徑。
- 交付模型、對照圖、實測比例與仍可見的差異。把曾經失敗的檢查寫進可重跑的驗證，尤其是髮根、服裝底下的暗色區、換裝後的接點及左右兩側接縫。

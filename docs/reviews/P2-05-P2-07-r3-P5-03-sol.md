**B2｜中｜木的開場治療全部溢補**

`trait_wood_photosynthesis` 的 8% 治療是 `on_summon` 當下立即結算。`duration_ms=6000` 不會產生持續治療。

三階理論回復量為 **64／74／86 HP**；滿血開場的實際回復均為 **0**。受傷後再次上場才可能取得價值。

**提案：**改為 `on_hp_cross_below{percent:50,duration_ms:6000}`，保留 **8%** 治療，使用現有每場一次的門檻事件。此提案尚未重跑勝率。

**B3｜中｜火特性只對火屬性受擊有效**

`trait_fire_thermal_recharge` 要求受到 **fire** 命中。其餘九線的精通招式均非 fire，因此本次所有跨線對戰中，火自身的縮 CD 特性觸發次數為 **0**。

**提案：**觸發屬性 `fire→any`，CD 修正 `−25→−10%`，持續 `5000→8000 ms`。較低幅度換取較廣的適用條件；須重新模擬。

**B4｜中｜土成年特性存在確定的攻擊相位失效**

土三階有效 CD 為 **862／2334／5384 ms**，受擊專精增益持續 **4000 ms**。

土成年對日成年時，雙方 CD 都是 **5384 ms**。每輪同時攻擊，土在傷害結算後才取得增益，而增益在下一輪之前到期，故土攻擊享有增益的次數為 **0**。含／不含土特性的結果相同。

**提案：**持續時間 `4000→6000 ms`，專精 `+15→+10` 百分點。這能跨過該相位斷點，同時降低幼年、少年頻繁受擊時的增幅。

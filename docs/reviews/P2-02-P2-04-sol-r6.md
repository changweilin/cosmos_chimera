### R2 · low · 精確同向目標被虛假夾角推到矩形後方

位置：

- `Assets/_Project/Features/Combat/Runtime/Model/HitVolume.cs:428`：兩個方向分別以 float 正規化，再計算夾角。
- `Assets/_Project/Features/Combat/Runtime/Model/HitVolume.cs:455`：float 切向投影決定方位。
- `Assets/_Project/Features/Combat/Runtime/Model/HitVolume.cs:325`：Post 承諾 footprint 接觸且高度符合時命中。

最小反例：

```csharp
var planet = new PlanetConfig(640f, float3.zero);
var front = MoveGeometry.Build(
    MoveShape.Front, MoveMovement.None, RangeClass.Melee,
    BurstOrigin.Caster, 2000, 0, stats, defaults);

var anchor = new float3(380f, 236f, 213f);
var target = anchor * (1025f / 1024f);
var forward = PlanetFrame.At(planet, anchor).North;

bool hit = MoveGeometry.Overlaps(
    front, planet, anchor, forward, target, 1e-6f);

// 預期 true；實際 false。
```

所有 Pre 均成立。比例為二進位精確值，實際 float 輸入的 double 原始叉積恰為零：

```text
target                = (380.37109375,236.23046875,213.2080078125)
anchor 半徑           = 495.44424509726622 m
target 半徑           = 495.92807736786904 m
真實測地距離          = 0 m
真實高度差            = 0.48383227060281797 m
允許高度差            = 1.000001 m
```

但 `Local` 算出：

```text
x = −0.000013206565199652687 m
z = −0.0000066032825998263434 m
```

目標因此被放到矩形後方，超出 `1e-6 m` 的目標半徑而漏判。影響此見證的是微米級判定體；半徑 0.5 m 時會命中。

**建議修正：** 在原始相對向量上以 double 計算叉積、內積與夾角，保證同向共線輸入的平面距離為零；切向方位亦避免先量化為 float。補上精確比例座標的回歸，並保留遠半球與近對蹠回歸。

### R3 · low · float 徑向長度相減違反高度判定 Post

位置：`Assets/_Project/Features/Combat/Runtime/Model/HitVolume.cs:415` 的相對座標，以及 `:431` 的 `height = rp - ra` 均為 float。

最小反例使用正式 defaults、半徑 **0.5 m** 的目標：

```csharp
var planet = new PlanetConfig(8000f, float3.zero);
var burst = MoveGeometry.Build(
    MoveShape.Burst, MoveMovement.None, RangeClass.Melee,
    BurstOrigin.Caster, 2000, 0, stats, defaults);

var anchor = new float3(4096f, 32f, 0f);
var target = anchor * (8195f / 8192f);

bool hit = MoveGeometry.Overlaps(
    burst, planet, anchor, float3.zero, target, 0.5f);

// 預期 false；實際 true。
```

兩點精確同向，測地距離為零，且均在嚴格殼層內：

```text
target             = (4097.5,32.01171875,0)
真實高度差         = 1.5000457756686956 m
高度上限           = 1 + 0.5 = 1.5 m
float 算得高度差   = 1.5 m
```

實際高度超限約 **0.0458 mm**，卻被接受。

另有內側漏判見證，使用相同 burst／目標半徑：

```text
planet.Center = (−16000,16000,8000)
anchor = (−7311.14599609375,6906.2275390625,10301.33984375)
target = (−7310.12744140625,6905.16162109375,10301.609375)

真實測地距離      = 0.00023782493038723566 m
真實高度差        = 1.4987600894364732 m
float 算得高度差  = 1.5009765625 m

預期 true；實際 false。
```

此例距高度上限尚有約 **1.240 mm**，仍被拒絕。

**建議修正：** 如 `ResolveAnchor`，先將世界座標升為 double，再減球心；徑向長度、差值及高度比較保持 double。補正常 defaults、正目標半徑及偏移中心的高度兩側回歸。

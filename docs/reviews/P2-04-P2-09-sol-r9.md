## D1 · medium · 未限制 dash 長度，無法滿足距離及自身 Rect 遠端的 Post

**位置：**

所有輸入均符合目前 Pre。R＝640、caster 半徑＝640、沿正切向前進：

| DashDistanceMm | caster→end 測地距離（m） | 自身 Rect 命中¹ |
|---:|---:|---|
| 1,005,309 | 1005.3090000000191 | true |
| **1,005,310** | 1005.3100000000085 | **false** |

| **4,021,239** | **0.00040340505074704314** | true |

¹ target radius＝0.002 m。

超過四分之一圓周，終點就可能被自身判定體拒絕；超過半圓周，最短測地距離不再等於行進長度；多圈後則回到起點附近。這不是毫米級量化誤差。

以下片段可直接加入現有 `DashDisplacementTests`，沿用其 `Dash`、`GeodesicM`、`PostSlackM`：

```csharp
[TestCase(1005310)]
[TestCase(2011000)]
[TestCase(4021239)]
[TestCase(int.MaxValue)]
public void D1_all_accepted_dash_lengths_meet_the_documented_post(int mm)
{
    var planet = new PlanetConfig(640f, float3.zero);
    var caster = new float3(640f, 0f, 0f);
    var forward = new float3(0f, 0f, 1f);
    HitVolume volume = Dash(mm);

    float3 end = MoveGeometry.ResolveDashEnd(
        volume, planet, caster, forward);

    Assert.AreEqual(
        mm * 0.001, GeodesicM(planet, caster, end), PostSlackM(end));
    Assert.IsTrue(MoveGeometry.Overlaps(
        volume, planet, caster, forward, end, 0.002f));
}
```

**預期：** 每個被接受的輸入均符合距離及自身 Rect 遠端承諾。  
**實際：** 上述四例全部違反至少一項承諾。

**建議修正：** 若維持現有 `Overlaps` 的半球規則，dash 的可接受角度必須受限於四分之一圓周，並處理浮點落點跨過 90° 邊界的餘裕。上限應依 **caster 實際半徑 rc** 計算，不能只依 planet.Radius。同步更新 Pre、呼叫端及邊界測試。若要支援長距離或多圈 dash，則須重新定義距離 Post 與沿途判定，不能只保留目前單一 Rect。

```csharp
public void D2_clamped_end_is_not_always_inside_its_own_rect_height()

        MoveShape.Line, MoveMovement.Dash, RangeClass.Melee,
        default, 1000, 0, _stats, defaults);

    float3 end = MoveGeometry.ResolveDashEnd(
        volume, planet, caster, forward);

        volume, planet, caster, forward, end, 0.002f));
```

```text
合法殼層 slack       = 0.01728 m
caster 半徑         = 319.990234375 m
end                 = (16320, 16000, 16001)
end 半徑            = 319.99960938072206 m
徑向高度差           ≈ 9.375 mm
允許高度差           = 1 + 2 = 3 mm
Overlaps             = false
```

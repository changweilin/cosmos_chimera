## Q-C18 契約核對

`NotifyHpChanged` 的契約與檢查一致：

- `Effects.cs:500、508`：明列並檢查 `maxHp >= 1`、舊／新 HP 均在 `0..maxHp`。
- `Effects.cs:513 → Fire:580 → Advance:602`：不論是否觸發，都經 `CombatTime.Require` 檢查時間域與水位。
- 時間域為 `0..2^62`；命令推進水位，查詢不推進。
- 非法時間不會先消耗觸發次數。

百分比使用 Int64 交叉相乘，沒有先取整。對整數 HP，等價邊界為：

```text
previousHp >= ceil(percent × maxHp / 100)
1 <= hp <= ceil(percent × maxHp / 100) - 1
```

已實跑的追加檢查包括：

| 檢查 | 結果 |
|---|---|
| HP 恰等於門檻 | 不觸發 |
| 舊 HP 恰等於門檻，再跌破 | 觸發 |
| 由門檻以上直接跌到 0 | 不觸發、不消耗次數 |
| 0 → 門檻以下 → 門檻以上 → 再跌破 | 只在最後一步觸發 |
| 多次跨越、效果到期後再次跨越 | 都不再次觸發 |
| Clear 後再次跨越 | 重新觸發 |
| p＝1，maxHp＝101，2 → 1 | 觸發 |
| p＝100，maxHp＝`int.MaxValue` | 正確處理 |
| duration＝1／600000 | 半開視窗與到期邊界正確 |
| 純治療、duration＝1／600000 | 立即回傳治療，不建立 timed slot |
| `max_stacks＝3` | 首次事件只建立 1 層；再次跨越不加層 |

## 其餘核對結果

`material_sum_overflow` 的合法整數接受域一致：

| 素材輸入 | schema | importer | Python 加總檢查 | C# requirement |
|---|---|---|---|---|
| 同鍵 `(MaxValue−1)+1` | 單筆合法 | 接受 | 無錯誤 | 合併為 MaxValue |
| 同鍵 `MaxValue+1` | 單筆合法 | 拒絕 | `material_sum_overflow` | Editor 拋 `ContractException`；Release 拋 `OverflowException` |
| F1×MaxValue、F2×1 | 合法 | 接受 | 無錯誤 | 保留兩個獨立鍵 |

schema 負責單筆範圍；跨筆合計由 validator／importer 補足。這個分工符合 C2 修法，沒有把 schema 單獨接受原反例重新列為缺陷。

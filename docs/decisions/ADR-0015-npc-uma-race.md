# ADR-0015：路人 NPC 改用日系 UMA 自訂種族，保留程序化多樣性

## 狀態
已採納（2026-11-23 定案 Q-A10）。補充 ADR-0014（NPC 也使用同一組日系 UMA 種族）。規格與多樣性對照見 `docs/design/npc-uma-looks.md`。

## 背景
- 路人 NPC（P3-18）目前由 `Bootstrap/Demo/NpcMeshes` 直接以程式生成網格，`characters.md` 定位為基底模型到位前的佔位。
- 程式生成的臉、頭身比、髮束難達日系 ACG 品質；主角與玩家角色已改走 ADR-0014 的 UMA 自訂種族，NPC 留在另一套會產生兩種畫風。
- 開放授權的現成日系紙娃娃系統不可用（ADR-0013：VRoid 禁止拿網格做角色生成、UMA 動漫種族僅女性、其他素材多無授權）。
- 換網格來源不得損失 `characters.md#路人-npc` 定義的多樣性（體型、臉、膚色、文化色、剪裁混搭、混血痕跡、種族招牌部件等連續抽樣）。

## 決定
1. **規則層不動**：`PopulacePlanner`、`NpcSpec`、`NpcHeritage`、文化種子與所有有界常態抽樣照舊。新增純 C# 對照器 `NpcSpec → UMA 配方描述`（DNA 值、slot id、色參數、掛骨部件），可 EditMode 測試，不依賴 UMA 執行期。
2. **種族覆蓋**：15 族共用 ADR-0014 人形身體。鳥人、狼人、蜥蜴人、龍人、魚人使用種族頭部 slot（取代頭部網格，吻長等以 blendshape 連續變化）；骷髏為獨立 UMA 種族；殭屍為人形＋貼花＋blendshape。動作、服裝、骨架全族共用。
3. **剛性部件**（角、喙、獠牙、耳鰭、冠羽、背棘、光環、職業道具、拐杖）沿用 `NpcMeshes` 的程序化生成，掛到 UMA 骨骼，保留連續形狀；材質改為卡通渲染＋描邊。
4. **顏色**：膚色、髮色、虹膜、衣物染色、強調色、織邊寬、emission 一律走 shader 參數，不烘進 atlas；同部件組合的 NPC 共用貼圖。
5. **替換門檻**（三項全過才替換）：① 對照完整性 EditMode 測試（每個外觀欄位都有對應，單獨改一欄配方輸出必變）；② 分布測試（每顆星球 1000 人，DNA 上下限不截斷抽樣極值、同聚落配方重複率低於門檻）；③ 同 seed 新舊並排截圖（`COSMIMERA_CAPTURE`），由使用者目視 15 族剪影可辨。
6. **舊程序化人形**：門檻通過後移除 `NpcMeshes` 的人體與頭部生成，只保留第 3 點的剛性部件。
7. **時程**：排在 ADR-0014 的種族、slot、DNA converter 完成之後。

## 後果
- `tools/acg-character/` 需多匯出 blendshape target：MPFB `game_engine` 骨架無臉骨，臉型與約 30 個臉部連續欄位只能靠 blendshape，每欄需正負兩向，並在日系化後的臉上重新烘；身體需分段（上臂、前臂、大腿、小腿、腹、臀）肌肉／體脂 target。
- 每件服裝 slot 要帶與身體同名的 blendshape 並適配男女身形，否則體脂變化會穿模。
- 需另做：種族頭部 slot 5 組、骷髏種族、髮型 9 與鬍鬚 6 slot、剪裁 7 種（上衣／下身分開）、時代附加與地區配件 slot、翼／尾／披風骨鏈 slot。
- 第 4 點能否與 UMA＋URP 卡通渲染配合需先實測；若不可行，回報使用者再議，不自行改回 atlas 或量化色票。
- DNA 上下限必須涵蓋 Irwin–Hall ±3.46σ。

## 替代方案
- 每個獸型種族各建 UMA 種族：服裝逐族適配，工時約 ×6；未採用。
- 獸型種族留在 `NpcMeshes`：同聚落兩種畫風；未採用。
- 剛性部件改手工 slot 預製變體：連續抽樣變離散；未採用。
- 每 NPC 一張 atlas＋快取：Steam Deck 記憶體與生成時間風險；未採用。
- 量化色票：失去連續內插與文化色偏移；未採用。
- 只以截圖驗收：看不出截斷與漏接欄位；未採用。
- 保留舊程序化人形作低模／備援：兩套維護；未採用。

問題「習性」6 階的生態學名稱，以及資料欄位／ID 是否一起改。「性格→習性」已定案，但各階新名稱未定。提案（依行為生態學的反掠食／領域行為用語）：

timid 膽怯 → 迴避（avoidant，0 m）· cautious 警惕 → 警戒（vigilant，4 m）· normal 沉穩 → 耐受（tolerant，8 m）· territorial 領地 → 護域（territorial，14 m）· fierce 凶悍 → 攻擊（aggressive，20 m）· apex 霸主 → 優勢（dominant，28 m）

改 ID 的代價：Data／產生的 asset／balance.json#ai.territory_mm／棲位提案／forge 的 catalog.js、designed.js、creature schema 都要同步遷移；只改顯示名稱則只動字串。

暫定無（牽涉 schema 與程式，不只 Data 數值）

Q-C62影響 P3-31RunPlanner

問題「相同生態棲位的不同種宙獸，巡邏範圍不可相同」的意思。可能是 (a) 空間上不重疊——生態學的競爭排斥：同棲位的兩個物種不共用同一片活動區（同種個體可重疊）；或 (b) 數值不同——同棲位的各物種 radius_mm 取不同值；或兩者皆要。另需決定衝突時怎麼處理，以及沒有活動半徑的「無限制隨機」棲位（食腐、機會型雜食、巡獵）怎麼算。

暫定無（決定生成演算法，需升 GeneratorVersion）

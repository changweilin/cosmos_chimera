待使用者決定的點。未決時：有「暫定」且只影響 Data/ 數值 → 照暫定實作；否則該項目停下，其他項目照做。 open-questions.answers.json 會記錄使用者決定。 定案後寫入對應設計文件並刪除該卡片與answers（定案歷史看 git）。
維護：每題一張 <article id="Q-xxx">，放進對應 <section>；欄位固定為 問題／影響項目／暫定（無暫定寫 無）。

選擇會自動存在這個瀏覽器（localStorage）。agent 讀不到——按「複製決策」貼回對話，或下載 JSON 存成 docs/open-questions.answers.json。

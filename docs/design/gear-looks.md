# 程序化器物外觀：服裝、飾品、武器、防具（P1-17）

服裝、飾品、武器、防具的外觀由 seed 程序化組合，差異來自五個軸：地區文化、時代文化、功能、外觀風格、新舊與毀損。美術目標為開放世界頂級卡通渲染的水準（只對標品質，不仿任何作品造型）。數值全部暫定。

## 範圍
| 出現處 | 呈現 |
|---|---|
| 路人 NPC 穿戴與職業道具 | 取代 `NpcMeshes` 現行服裝與道具網格；抽樣規則沿用 [characters.md#路人-npc](characters.md#路人-npc) 的剪裁／混搭，五軸由本文件補上 |
| 玩家角色裝備 | **紙娃娃**換裝：上身、下身、頭飾、飾品換掉角色對應部位外觀；武器與盾掛 `Socket_HandR_Prop`／`Socket_HandL_Prop`（大廳預覽 `PaperdollPreview`） |
| 宙獸裝備 | 武器與盾由**虛擬大手**持握（[art-asset-pipeline.md#武器持有動作格式](art-asset-pipeline.md#武器持有動作格式)，`Socket_Weapon_R`／`_L`）；宙獸本體不畫防具，**上身／下身防具只在格擋護盾特效出現時顯示其特徵**；飾品為小型掛飾，掛在 `Socket_Head` 或 `Socket_Core_FX` |
| 場景擺設 | 遺跡兵器架、戰場殘骸、武器展示等，依所在聚落／遺跡取軸 |

不在範圍：戰利品／寶箱掉落與商店貨品（經濟系統另議）。

器物類別取自物品資料：武器依 `equipment.weapon.weapon_type`（16 種，同 [crafting.md#武器數值模型](crafting.md#武器數值模型)；未填時單手畫成劍、雙手畫成大劍），盾、上身、下身、飾品依 `equipment.kind`。

## 美術路線（分段）
1. **規則層**：`GearLooks.Sample` 由（器物類別、用途情境、風格混合、新舊／毀損平均、seed）抽出 `GearLookSpec`。純 C#、可重現（同 seed 同結果，只用 `Pcg32`），可 EditMode 測試。
2. **佔位網格**：程序化網格依 `GearLookSpec` 組裝，供實景驗收比例與配色。
3. **手工部件庫**（P1-16）：每類器物 3–6 個手工底型 × 部件槽，部件帶手繪 trim sheet 與部件貼圖；只換網格與貼圖來源，`GearLookSpec` 與抽樣規則不變。製作走 [art-asset-pipeline.md](art-asset-pipeline.md)。

部件槽（佔位與部件庫共用）：
| 類別 | 部件槽 |
|---|---|
| 近攻刃器（匕首、劍、斧、大劍、雙頭刃、長槍） | 刃身、護手、握柄、柄頭、刃面紋樣 |
| 鈍器（錘、巨錘、長棍） | 頭部、柄、握把纏繩、配重 |
| 弓弩（手弩、連弩、獵弓、長弓、重弩） | 弓臂、握把、弦／機括、箭槽 |
| 法器（短杖、魔導銃、法杖、巨砲杖） | 杖身、杖頭／槍口、核心（可發光）、纏飾 |
| 投擲（飛刃、投矛） | 刃身、握段、尾羽／穗 |
| 盾 | 盾體、盾心、盾緣、紋章 |
| 上身／下身 | 剪裁底型、領、袖／褲管、下襬、鑲邊、護片 |
| 頭飾、飾品 | 底型、主飾、垂飾 |

## 外觀與數值
- **純表現**：同配方成品數值相同；外觀不影響任何戰鬥或製作數值。所有純外觀換裝（時裝、染色、二周目已獲得角色與其服裝／飾品切換）統一於裝備更換系統操作，並支援**純外觀我的最愛**預設切換。
- 每件成品帶一個**外觀標記**（製作所在星球的類型與 seed，及每件外觀 seed），存進存檔；風格由星球推得（`ArchitectureMeshes.PlanetStyleFor`）。
- **大廳製作**取最近一次出發的星球；從未出發則取搖籃星。
- 背包仍以堆疊顯示數量，**堆疊內每件各記外觀標記**；舊存檔的成品依物品 id 與序號補標記（取搖籃星）。
- 同一種成品有多件時，手冊換裝可左右切換預覽、挑選要穿的那一件；卸下時該件連同外觀回到背包。配方消耗成品時取最後製作的一件。
- 不做耐久、不隨使用磨損：玩家成品出廠為全新（新舊 0、毀損 0）。

## 五軸
| 軸 | 定義 | 來源 |
|---|---|---|
| 地區文化 | 6 個星球傳統（同建築 `ArchRegion`）：決定配色、材質、招牌紋樣 | NPC／擺設：所在聚落的主／副／第三風格混合（[settlement-structures.md#建築造型](settlement-structures.md#建築造型)）；玩家成品：製作所在星球 |
| 時代文化 | 8 個時代（同 `ArchEra`，遠古＝出土遺物）：決定造型語彙與工藝 | 同上 |
| 功能 | 器物類別 × 用途情境 | 見下表 |
| 外觀風格 | 每件一次有界常態抽樣（Irwin–Hall，同建築） | 見〈同類內的隨機性〉 |
| 新舊／毀損 | 新舊：褪色、髒污、握把磨亮；毀損：缺口、裂紋、斷柄、補丁、鏽蝕 | NPC：聚落 `AgeMean`／`DamageMean`；遺物：遠古基準；玩家成品：0 |

### 功能（用途情境）
| 情境 | 輪廓與裝飾 | 誰會抽到 |
|---|---|---|
| 戰鬥 | 輪廓銳利、護片多、裝飾少 | 玩家與宙獸成品固定；NPC 守衛 |
| 勞動 | 粗壯、耐磨、無裝飾、工具化 | 農夫、礦工、工匠、搬運工、漁夫、採集者、無職業者與兒童 |
| 禮儀儀式 | 修長、對稱、紋樣密、可發光 | 祭司；遺物 |
| 旅行防候 | 包覆、多層、斗篷與袋 | 商人、表演者、醫者 |
| 身分裝飾 | 鑲邊、寶石、色彩飽和 | 領袖、學者 |

### 同類內的隨機性（每件一次有界常態抽樣）
| 面向 | 平均 | 每件偏移 | 外觀 |
|---|---|---|---|
| 混合 | 聚落 `ArchMix.Weight` | σ 0.18 | 配色、紋樣、部件逐項擲硬幣借副或第三風格（同 NPC 混搭） |
| 比例 | 1 | 長 σ 8 %、寬 σ 10 %、厚 σ 12 % | 刃長、柄長、盾徑、衣長 |
| 曲率 | 情境基準 | σ 0.15 | 刃彎、弓臂反曲、衣襬弧度 |
| 紋樣密度 | 情境基準 | σ 0.15 | 紋樣與裝飾件數量 |
| 配色 | 地區色票 | 色相 σ 0.03、明度 σ 0.06 | 主色、副色、金屬色 |
| 部件底型 | — | 各槽均勻抽 | 部件庫每槽 3–6 個底型 |
| 新舊 | 來源平均 | σ 0.15 | 褪色、髒污、握把磨亮 |
| 毀損 | 來源平均 | σ 0.12 | 缺口、裂紋、斷柄、補丁、鏽蝕（金屬）／蟲蛀（布、木） |

## 宙獸格擋護盾
格擋護盾特效顯示宙獸上身與下身防具的特徵（純表現）：
- **上身**決定護盾配色與時代紋樣，**下身**決定護盾邊框紋樣；只裝一件時配色、紋樣、邊框全取該件；都沒裝時為無紋樣的元素色護盾。
- 毀損高者護盾帶裂紋。
- 持盾宙獸的盾本體照常由虛擬大手顯示。

## 宙獸飾品
小型掛飾（垂飾、護符、環飾），依體型掛在 `Socket_Head` 或 `Socket_Core_FX`，大小隨宙獸身高縮放；外觀同樣由 `GearLooks.Sample`（`GearKind.Accessory`）抽樣。

## 可重現
外觀屬純表現，不進 `RunLayout` 雜湊；但同（外觀 seed、軸）各客戶端畫出相同器物。生成邏輯禁用 `UnityEngine.Random`，只用 `Pcg32`；有界常態用四個均勻亂數之和，不用 log／sqrt。

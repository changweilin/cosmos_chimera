# 願景與支柱

## 一句話
在每場都不同的小星球上，帶著宙獸隊伍探索、戰鬥、收服，然後回到地球仰望下一顆星。

## 設計支柱
1. **一顆可以繞一圈的星球** — 走到地平線另一端會回到原點；星球小到能感受曲率、大到能迷路。
2. **熟悉又陌生的地貌** — 以真實地理為骨架（海岸線、山脈、河系、聚落紋理），以程序化房間/遺跡/地城填肉。
3. **宙獸是戰友不是道具** — 即時動作戰鬥中召喚、輪替、搭配副手；隊伍構築就是 build。
4. **一場一星的節奏** — 每顆星球是一場 run：探索 → 任務/BOSS → 收服/得蛋 → 回大廳。

## 畫風與沉浸感（目標，技術見 `architecture/planet-tech.md`）
- URP 卡通著色：2–3 階柔和明暗 + 邊緣光 + 大氣散射遠景；描邊只用於角色與宙獸（地形不描邊，保持水彩感）。
- 風場驅動草、樹、毛髮、布料；GPU instancing 大量草叢。
- 天空：日夜循環 + 星海（與大廳的星海同一套資源，強化「我在宇宙中」）。
- 鏡頭：第三人稱為主，可切第一人稱；up 永遠是當地地表法線。

## 範圍
- 星球直徑為參考作的 2–8 倍：參考 R=160 m → 本作 **R = 320–1280 m**，依星球類型決定（見 `planet-world.md`）。
- 單機完整可玩；多人 1–4 人為加值功能（見 `multiplayer.md`）。
- **平台**（Q-T4 定案）：Windows PC（Steam）＋ Steam Deck。
  - Steam Deck 跑 Windows 建置（透過 Proton），不另出原生 Linux 版；以 Steam Deck Verified 為目標。
  - Steam Deck 是**效能下限**：800p、30–40 fps 穩定；PC 目標 60 fps。LOD 距離、草密度、陰影品質要有 Deck 預設檔。
  - 從第一天起就要支援手把；UI 字級符合 Deck 7 吋螢幕可讀性；不能有只靠滑鼠的操作。

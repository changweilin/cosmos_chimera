# 採集、加工與裝備

Q-W21 的原料／製作用途接成可玩的生活循環；場景物件與穿戴外觀維持現狀。食材與料理沿用 Food，進化素材沿用 MaterialInventory；本系統的原料、成品與裝備另存，不互相充當材料。

## 採集與技能來源

- 延伸既有生活能力的用途，每個宙獸型態仍只有一個 `field_utility`，主力與副手器皿資格沿用 [field-utilities.md](field-utilities.md)。不以隊伍中任意一項屬性專精直接解鎖能力。
- 金的 `magnet_pickup_double` 採金／銀／銅／鐵礦；土的 `drop_rate_up` 採煤、晶石、寶石原礦與石材。持有製作的礦鎬可代替這兩種採礦資格，工具不消耗。
- 木的 `forage_berries` 可採木材（含立木：闊葉樹、針葉樹、傘形樹、沼澤樹）、麻纖維、棉花與染料植物。棉花限夏季；其他原料的來源與季節以資料為準。
- 採集限角色周圍互動距離內的完整散佈物件；同一物件每場只能成功採一次。破壞後不能採（例外：持對應生活技能的宙獸以主動技擊倒即算收成，見 [destructibles.md#傷害](destructibles.md#傷害)）、滿背包不耗掉節點；採集不改網格、不改碰撞、不使原物件消失。既有灌木代表棉花資源，尚不新增棉株造型。
- 狩獵陷阱回收時同時取得絲繭與羽絨，供紡織及衣物製作。沿用既有陷阱的 30 秒模擬時間與最多 3 個限制；手冊暫停時不成熟。這些材料目前不限制季節。

## 加工與製作

- 火的 `cook_fire` 熔煉礦錠及琉璃珠；木的 `forage_berries` 紡織、抽絲、提染料、造紙、裁縫與製作符籙／陷阱；金的 `magnet_pickup_double` 鍛造、工具與魔術方塊；光的 `scout_potential` 切磨珠寶與製作飾品。
- 在冒險手冊「生活技能」操作，可在星球或大廳製作；只列符合資格的配方，亦可展開查看未解鎖項目。顯示各材料的持有量／需求量與工具需求。
- 先驗證技能、工具、全部材料與成品容量，再一次完成扣料與給成品；重複材料 ID 先加總。拒絕時全部不變，不截斷成品數量。
- 縫紉針屬於配方工具，只檢查持有、不扣除；礦鎬在背包中即可生效。目前不設工具耐久與熟練度。
- 製作的三種收服器皿須在「道具」明確選用；每次有效收服嘗試消耗一個，成功或失敗均消耗，沒有目標不消耗。本次收服率增加 **15 個百分點（暫定）**，仍套用原本上限；切換器皿會取消選用。基本器皿沿用既有行為。
- 製作的採集陷阱消耗一個即可佈置，不要求隊伍有 `set_trap`；地點／數量不符不消耗。回收先檢查原料背包容量，避免材料無處可放時清掉陷阱。

## 穿戴與數值

- 玩家及每隻已擁有宙獸各有右手、左手、上身、下身、飾品五槽；僅在大廳手冊「道具」換裝。本輪介面以玩家與目前主力為穿戴對象，離開隊伍的宙獸保留裝備。
- 裝備從背包移到穿戴槽，不能再作為配方材料；替換／卸下將舊裝備放回背包，容量不足則整次拒絕。每份成品只能給一個穿戴者。
- 暫定數值：鐵刃限宙獸（金專精 +15）；鐵甲給玩家最大 HP +15%、宙獸全抗性各 +5；麻衣給雙方移速 +5%；羽絨衣給玩家最大 HP +10%、宙獸冰抗性 +10；寶石墜飾給玩家翻滾冷卻 −10%、宙獸全屬性主動技冷卻 −5%。資料列保有各自適用對象，玩家尚無個人武器攻擊流程。
- **槽位**：武器分單手／雙手（各分近攻／遠攻），防具分盾／上身／下身，另有飾品。右手放單手或雙手武器；左手放單手武器（雙持）或盾；雙手武器佔兩手，換上時左手物品放回背包，左手換上東西時雙手武器放回背包。每隻宙獸（依物種）固定使用 **1** 種持握方式：雙手武器／雙持單手／單手＋盾（御三家分別為：日 `one_hand_shield` 單手＋盾、月 `dual_wield` 雙持單手、星 `two_handed` 雙手武器）；**近攻與遠攻皆有這三種持握方式**。以持盾單手武器為基準 100% DPS：雙手武器佔左右手兩個武器槽（製作需求與武器附加屬性為單手武器的 2 倍），傷害 +35%（135% DPS）；雙持單手武器保持雙手輪流揮動，攻速額外 +25%。武器如《暗黑破壞神 IV》各有屬性、基礎攻擊倍率與基礎攻速，兩把武器的差異會造成不同效果。武器只追加攻擊面效果（命中、爆率、爆傷等；同屬性專精 +N 仍屬武器）、防具只追加防守面效果（失衡值、格擋減免率等，定義見 [combat.md#格擋](combat.md)、〈失衡與擊退〉）、飾品只提升元素類效果（元素抗性或額外元素傷害）。持盾時格擋值由 35% 提高到 75%（[combat.md#格擋](combat.md)）。
  - 只持一把單手武器（左手空）時，雙持或單手＋盾任一持握方式即可。
  - 手上組合不符目前持握方式（例如進化後持握方式改變）時，兩手裝備都不生效，但仍留在槽內，可卸下；其他槽照常生效。
  - 玩家角色可穿全部槽，只取防守與元素效果：武器不給玩家任何加成（資料中武器的玩家欄位必須為 0），盾與防具照給玩家加成。盾與防具可給玩家陰守／陽守點數，加在玩家的等級底值上（[combat.md#玩家角色的守](combat.md#玩家角色的守)）。
  - 副手 25% 換算只含效果列，不含持握加成（+35%／+25%）與武器基礎倍率。
  - 舊存檔遷移：武器 → 單手武器、防具 → 上身、飾品 → 飾品。

    - **攻速**換算成全主動技 CD 倍率（攻速 1.2 → CD ÷ 1.2），雙持再額外 +25% 攻速。

## 製造擴充（D0-U4，排在 D0-U3 之後）
<a id="製造擴充"></a>

- **品項**：依 D0-U3 槽位（近攻／遠攻之單手／雙手武器、盾、上身、下身、飾品）補齊品項，每槽每材質階一組。
- **防具類型**：盾、上身、下身各設多種類型；同部位同星等的不同類型**除了陰陽守分工（3★ 材質分線）外只差在外觀**，基礎能力值總和、製作消耗與附魔詞綴池皆相同：
  - **盾**：圓盾、鳶盾、塔盾（鍛造金屬盾）；木圓盾、符紋盾、長方木盾（木工木盾）。
  - **上身**：胸甲／板甲、鎖甲／鱗甲（鍛造金屬甲）；短衣／外套、長袍／斗篷（裁縫布衣）。
  - **下身**：護脛／膝甲、板甲腿裙（鍛造金屬下裝）；長褲、戰裙／輕裙（裁縫布褲）。
- **材質三階與基礎能力值**：各材質線分 **1★／2★／3★** 三個星等，加工比例統一為 **10 份原料 → 1 份加工材料**：
  - **金屬**：銅 → **青銅**（1★）、鐵 → **不鏽鋼**（2★）、銀 → **秘銀**（3★，陰攻武器）、金 → **精金**（3★，陽攻武器）。
  - **布料**：麻 → **纖維複合麻**（1★）、棉 → **雙織厚棉**（2★）、絲 → **穹綾紗**（3★，陰防防具）、毛（含羽絨與羊毛）→ **熾陽絨**（3★，陽防防具）。
  - **木料**：原木 → **層壓複合木**（1★）、硬質木 → **碳化硬木**（2★）、月杉木 → **月杉凝木**（3★，陰攻遠攻武器／陰防木盾）、日輪木 → **日輪重木**（3★，陽攻遠攻武器／陽防木盾）。
  - **珠寶**：飾品一律使用**珠寶**製作（寶石加工成珠寶；寶石屬性只影響外觀，不影響元素與抗性）。**寶石／珠寶／魔法石皆為 3★ 素材**（飾品 1★／2★ 加工材料放 `Data/`）。
  - **裝備製作需求**（單手武器／防具／飾品基準；雙手武器依前述規則為 **2 倍**）：
    - **1★ 裝備**：4 份 1★ 加工材料
    - **2★ 裝備**：16 份 1★ ＋ 4 份 2★ 加工材料
    - **3★ 裝備**：64 份 1★ ＋ 16 份 2★ ＋ 4 份 3★ 加工材料
  - **基礎能力值與陰陽分工**：1★／2★ 武器與防具的陽／陰點數預設**均分**，3★ 依上述材質分線（秘銀／月杉凝木＝陰攻、精金／日輪重木＝陽攻；穹綾紗／月杉凝木＝陰防、熾陽絨／日輪重木＝陽防；細項分配放 `Data/`）：
    - **武器**（單手／雙手）：只提供 **`[速度 / 陽攻 / 陰攻]`**，三項綜合值依星等為 **15 / 30 / 45 點**（雙手武器依前述「附加屬性為單手 2 倍」規則為 **30 / 60 / 90 點**；武器仍不給玩家角色能力加成）。
    - **防具**（盾／上身／下身）：只提供 **`[HP / 陽守 / 陰守]`**，三項綜合值依星等為 **15 / 30 / 45 點**（玩家角色照常取盾與防具的 `陰守 / 陽守` 點數加在等級底值上）。
    - **飾品**：基礎能力值綜合值為 **0 點**（價值全來自附魔詞綴）。
- **製造技能八類**，由製造專屬 `field_utility` 提供，佔用該宙獸型態唯一的生活能力名額（每型態仍只有一個）：
  | 類別 | 產出 |
  |---|---|
  | 熔煉 | 礦 → 錠 |
  | 紡織 | 纖維 → 布 |
  | 裁縫 | 衣物防具、時裝 |
  | 鍛造 | 金屬武器、盾、甲 |
  | 木工 | 木製武器、盾、弓杖 |
  | 珠寶 | 切磨、飾品、萃靈加工（附魔媒介） |
  | 染色 | 時裝上色 |
  | 附魔 | 消耗附魔媒介為武器／防具／飾品賦予詞綴 |
- **持有物種**：製造專屬能力由 P5 新物種持有。在那之前由既有能力代行：火 `cook_fire` → 熔煉；木 `forage_berries` → 紡織、裁縫、木工、染色；金 `magnet_pickup_double` → 鍛造；光 `scout_potential` → 珠寶、附魔。
- **外觀**：防具提供數值；另有不加數值的時裝，可套在防具上改變外觀，時裝可染色。穿戴外觀資產後續補充，本項只做資料與規則。
- **耐久**：受擊、攻擊命中、盾格擋時扣耐久。歸零時裝備保留但失去加成，修理後恢復。
- **修理**三處：大廳手冊（消耗同材質原料）、星球上由同類製造能力修理、村落 NPC。
- **附魔與詞綴（三星等）**：成品的隨機詞綴改由**附魔**賦予，依 seed 可重現（`Pcg32`）。附魔分為 **1★ / 2★ / 3★** 三個星等，每階層數值區間不同（隨星等遞增，數值放 `Data/`）：
  | 裝備部位 | 附魔格數 | 可抽詞綴類型 | 詞綴池範例（暫定，沿用既有效果詞彙） |
  |---|---|---|---|
  | **武器** | **1 格** | **1 個攻擊面詞綴** | 命中（`accuracy_mod`）、爆率（`crit_rate_mod`）、爆傷（`crit_damage_mod`）、同屬性專精（`mastery_mod`）、攻速／CD 縮減（`cd_mod_percent`）；雙手武器數值為單手 2 倍 |
  | **防具** | **1 格** | **1 個防守面詞綴** | 失衡值（`stagger_capacity_mod_percent`）、格擋減免率（`block_reduction_mod`）、閃避率（`evasion_mod_percent`）、移速（`move_speed_mod_percent`） |
  | **飾品** | **2 格** | 每格各自抽 **1 個元素詞綴** 或 **3 個抗性詞綴** | 元素詞綴＝單一屬性專精，並讓該元素效果保底 **100%**（**先計算所有加成，最後計算保底**；CD 減免移至武器詞綴）；3 個抗性詞綴＝1 項主屬性抗性＋**另外 2 項隨機不重複屬性**的 `resist_mod` |
  - 附魔詞綴屬於裝備的 `CreatureEffects`，副手穿戴時依既有 25% 無條件進位規則換算給主力。重複對同一格附魔時覆寫該格既有詞綴（飾品可指定第 1 或第 2 格）。
- **附魔生活技循環（採集 ＞ 加工 ＞ 附魔）**（消耗材料獨立於收服用的琉璃珠與符籙）：
  1. **採集（`gather_essence`）**：從星球晶簇、特殊礦脈與異象節點採集 **星塵碎屑（1★）／乙太晶核（2★）／星髓結晶（3★）**（依星球階級與地貌分佈；P5 前由土 `drop_rate_up`／光 `scout_potential` 代行）。
  2. **加工（珠寶／萃靈加工）**：將採集的星塵／晶核／結晶搭配基礎晶石精煉為對應星等的 **初階附魔印石（1★）／中階附魔印石（2★）／高階附魔印石（3★）**（供武器／防具附魔）；另將 **寶石**（3★）加工為 **魔法石**（3★，供飾品附魔）。
  3. **附魔（`craft_enchant_<屬性>`）**：武器／防具消耗對應星等 **附魔印石**、飾品消耗 **魔法石**（3★），為目標裝備抽取並寫入該星等詞綴（`craft_enchant_<屬性>` 技能資格由主力或對應琉璃珠／符籙副手提供，P5 前由光 `scout_potential` 代行）。
- **原料品質與採集機率**：由採集節點星等與星球 seed 生成（依地貌與星球階級分佈，同 seed 同結果）。採集／收割不同星等礦產或作物時，依裝備消耗比（`16 : 4 : 1`）按比例機率獲得各星等原料：1★ 節點 100% 1★；2★ 節點 80% 1★／20% 2★；3★ 節點 16/21（≈76.2%）1★／4/21（≈19.0%）2★／1/21（≈4.8%）3★。
- **製造類生活技能**：生活技能在主動技／被動技之外擴充「製造類」；八類每類 2～3 個不同屬性的技能，同類技能**效果相同**，只差持有物種的屬性。每個技能另標副手器皿（符籙或琉璃珠），該器皿的副手才對隊伍提供它；魔術方塊副手不提供。ID 格式 `craft_<類別>_<屬性>`（例 `craft_smelt_fire`、`craft_enchant_light`）。

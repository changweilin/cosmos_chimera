# 採集、加工與裝備

Q-W21 的原料／製作用途接成可玩的生活循環；場景物件與穿戴外觀維持現狀。食材與料理沿用 Food，進化素材沿用 MaterialInventory；本系統的原料、成品與裝備另存，不互相充當材料。

## 採集與技能來源

- 延伸既有生活能力的用途，每個宙獸型態仍只有一個 `field_utility`，主力與副手器皿資格沿用 [field-utilities.md](field-utilities.md)。不以隊伍中任意一項屬性專精直接解鎖能力。
- 金的 `magnet_pickup_double` 採金／銀／銅／鐵礦；土的 `drop_rate_up` 採煤、晶石、寶石原礦與石材。持有製作的礦鎬可代替這兩種採礦資格，工具不消耗。
- 木的 `forage_berries` 可採木材、麻纖維、棉花與染料植物。棉花限夏季；其他原料的來源與季節以資料為準。
- 採集限角色周圍互動距離內的完整散佈物件；同一物件每場只能成功採一次。破壞後不能採、滿背包不耗掉節點；採集不改網格、不改碰撞、不使原物件消失。既有灌木代表棉花資源，尚不新增棉株造型。
- 狩獵陷阱回收時同時取得絲繭與羽絨，供紡織及衣物製作。沿用既有陷阱的 30 秒模擬時間與最多 3 個限制；手冊暫停時不成熟。這些材料目前不限制季節。

## 加工與製作

- 火的 `cook_fire` 熔煉礦錠及琉璃珠；木的 `forage_berries` 紡織、抽絲、提染料、造紙、裁縫與製作符籙／陷阱；金的 `magnet_pickup_double` 鍛造、工具與魔術方塊；光的 `scout_potential` 切磨珠寶與製作飾品。
- 在冒險手冊「生活技能」操作，可在星球或大廳製作；只列符合資格的配方，亦可展開查看未解鎖項目。顯示各材料的持有量／需求量與工具需求。
- 先驗證技能、工具、全部材料與成品容量，再一次完成扣料與給成品；重複材料 ID 先加總。拒絕時全部不變，不截斷成品數量。
- 縫紉針屬於配方工具，只檢查持有、不扣除；礦鎬在背包中即可生效。目前不設工具耐久與熟練度。
- 製作的三種收服器皿須在「道具」明確選用；每次有效收服嘗試消耗一個，成功或失敗均消耗，沒有目標不消耗。本次收服率增加 **15 個百分點（暫定）**，仍套用原本上限；切換器皿會取消選用。基本器皿沿用既有行為。
- 製作的採集陷阱消耗一個即可佈置，不要求隊伍有 `set_trap`；地點／數量不符不消耗。回收先檢查原料背包容量，避免材料無處可放時清掉陷阱。

## 穿戴與數值

- 玩家及每隻已擁有宙獸各有右手、左手、上身、下身、飾品五槽；僅在大廳手冊「道具」換裝。本輪介面以玩家與目前主力為穿戴對象，離開隊伍的宙獸保留裝備。
- 裝備從背包移到穿戴槽，不能再作為配方材料；替換／卸下將舊裝備放回背包，容量不足則整次拒絕。每份成品只能給一個穿戴者。
- 暫定數值：鐵刃限宙獸（金專精 +15）；鐵甲給玩家最大 HP +15%、宙獸全抗性各 +5；麻衣給雙方移速 +5%；羽絨衣給玩家最大 HP +10%、宙獸冰抗性 +10；寶石墜飾給玩家翻滾冷卻 −10%、宙獸全屬性招式冷卻 −5%。資料列保有各自適用對象，玩家尚無個人武器攻擊流程。
- **槽位**：武器分單手／雙手，防具分盾／上身／下身，另有飾品。右手放單手或雙手武器；左手放單手武器（雙持）或盾；雙手武器佔兩手，換上時左手物品放回背包，左手換上東西時雙手武器放回背包。每隻宙獸（依物種）只能使用 1～2 種持握方式：雙手武器／雙持單手／單手＋盾。雙手武器的效果為單手的 2 倍、佔兩個武器槽，持雙手武器時傷害 +30%；雙持單手武器左右輪流攻擊，攻速 +15%。武器如《暗黑破壞神 IV》各有屬性、基礎攻擊倍率與基礎攻速，兩把武器的差異會造成不同效果。武器只追加攻擊面效果（命中、爆率、爆傷等；同屬性專精 +N 仍屬武器）、防具只追加防守面效果（失衡值、格擋減免率等，定義見 [combat.md#格擋](combat.md)、〈失衡與擊退〉）、飾品只提升元素類效果（元素抗性或額外元素傷害）。持盾時格擋值由 35% 提高到 75%（[combat.md#格擋](combat.md)）。
  - 只持一把單手武器（左手空）時，雙持或單手＋盾任一持握方式即可。
  - 手上組合不符目前持握方式（例如進化後持握方式改變）時，兩手裝備都不生效，但仍留在槽內，可卸下；其他槽照常生效。
  - 玩家角色可穿全部槽，只取防守與元素效果：武器不給玩家任何加成（資料中武器的玩家欄位必須為 0），盾與防具照給玩家加成。
  - 副手 25% 換算只含效果列，不含持握加成（+30%／+15%）與武器基礎倍率。
  - 舊存檔遷移：武器 → 單手武器、防具 → 上身、飾品 → 飾品。
  - <a id="武器數值模型"></a>武器數值模型（Q-C57，結構定案、數值暫定，全部放 `Data/`）：
    - **攻擊倍率**乘在招式威力上（例：單手 0.9–1.1；雙手 = 單手 ×2 再 +30%）。
    - **攻速**換算成全招式 CD 倍率（攻速 1.2 → CD ÷ 1.2），雙持再 +15%。
    - **雙持輪流**：每次被接受的施招交替使用右、左手武器的倍率與攻速（從右手開始；被拒絕的施招不換手）。
    - **武器屬性**：當下出手的武器屬性與招式相同時，該招專精 +N（`weapon.element_mastery`）。
    - 物種（每個型態）的持握方式依體型與 `ai_style` 推導初稿：`charge`→雙手、`flank`→雙持、`keep_distance`／`hold`→單手＋盾；L 以上體型再加一種（主要為雙手者加單手＋盾，其餘加雙手），之後逐隻調整。資料：`Data/_incoming/life-crafting-draft-01/craft-grips/`。
    - 舊裝備：鐵刃＝單手、金屬性、專精 +15（取代原本的常駐金專精 +15）、倍率 1.0、攻速 1.0；鐵甲、麻衣、羽絨衣＝上身；寶石墜飾＝飾品（`Data/` 暫定值）。
- 出發時鎖定裝備。玩家加成套用至生命／翻滾設定及環境移動倍率；移速與冷卻相對修正各自加總，下限 −90%，翻滾冷卻不得短於翻滾動畫。
- 宙獸使用 `EffectBook.SetEquipmentEffects` 的獨立常駐層，不佔四個副手特性名額；每個效果只加一次，沿用既有專精／抗性／倍率上限。脫戰清理、淨化、升級與超載換天生特性均保留裝備加成。不可放瞬間治療效果。
- **副手裝備**：主力出戰時，其副手身上裝備的宙獸效果以 **25%** 強度加到主力的裝備常駐層；主力自己的裝備為 100%。副手裝備的玩家加成不適用。**每件各自**打 25% 後**無條件進位（遠離 0）**（+15 → +4、+5 → +2、−5 → −2），不先加總；主力自身與副手換算後的效果合計仍上限 32 個，超出的副手效果不套用（Q-C42）。

## 製造擴充（D0-U4，排在 D0-U3 之後）
<a id="製造擴充"></a>

- **品項**：依 D0-U3 槽位（單手／雙手武器、盾、上身、下身、飾品）補齊品項，每槽每材質階一組。
- **材質三階**：布料 麻 → 棉 → 絲；金屬 銅 → 鐵 → 銀／金（銀與金同屬第三階）。
- **製造技能七類**，由製造專屬 `field_utility` 提供，佔用該宙獸型態唯一的生活能力名額（每型態仍只有一個）：
  | 類別 | 產出 |
  |---|---|
  | 熔煉 | 礦 → 錠 |
  | 紡織 | 纖維 → 布 |
  | 裁縫 | 衣物防具、時裝 |
  | 鍛造 | 金屬武器、盾、甲 |
  | 木工 | 木製武器、盾、弓杖 |
  | 珠寶 | 切磨、飾品 |
  | 染色 | 時裝上色 |
- **持有物種**：製造專屬能力由 P5 新物種持有。在那之前由既有四項能力代行：火 `cook_fire` → 熔煉；木 `forage_berries` → 紡織、裁縫、木工、染色；金 `magnet_pickup_double` → 鍛造；光 `scout_potential` → 珠寶。
- **外觀**：防具提供數值；另有不加數值的時裝，可套在防具上改變外觀，時裝可染色。穿戴外觀資產後續補充，本項只做資料與規則。
- **耐久**：受擊、攻擊命中、盾格擋時扣耐久。歸零時裝備保留但失去加成，修理後恢復。
- **修理**三處：大廳手冊（消耗同材質原料）、星球上由同類製造能力修理、村落 NPC。
- **品質與詞綴**：成品品質取**主材料**的品質；品質越高，隨機詞綴數量越多。詞綴抽選須依 seed 可重現。
- **原料品質**：由採集節點本身決定，依地貌與星球階級分佈，由星球 seed 生成（同 seed 同結果）。
- **製造類生活技能**：生活技能在招式／特性之外擴充「製造類」；七類每類 2～3 個不同屬性的技能，同類技能**效果相同**，只差持有物種的屬性。每個技能另標副手器皿（符籙或琉璃珠），該器皿的副手才對隊伍提供它；魔術方塊副手不提供。ID 格式 `craft_<類別>_<屬性>`（例 `craft_smelt_fire`）。

  | 類別 | 琉璃珠 | 符籙 |
  |---|---|---|
  | 熔煉 | 火 | 金、雷 |
  | 紡織 | 木 | 風、影 |
  | 裁縫 | 木 | 影、光 |
  | 鍛造 | 金 | 火、土 |
  | 木工 | 木 | 土、風 |
  | 珠寶 | 光 | 土、冰 |
  | 染色 | 木 | 水、光 |

  器皿標記為暫定（`Data/` 欄位）：每類各留至少一個琉璃珠與一個符籙，兩種副手都能補齊該類；屬性欄已定案。

## 資料與保存

- 原始資料：`Data/_incoming/life-crafting-draft-01/`；35 種物品、21 張配方，依 `Data/schemas/craft-{item,recipe}.schema.json` 驗證。成本、產量、器皿加成與裝備數值為試玩暫定值。
- `python tools/demo-data/merge.py --crafting-only` 僅產生本系統 demo 資料及 `Crafting/Resources/Crafting` 的 TextAssets；不直接編輯生成檔。本系統三語文案位於同批次 `crafting-copy.json`。
- 存檔格式 **v7** 起有 `craft_stock` 與 `equipment`，**v9** 改為五槽（`main_hand`／`off_hand`／`upper`／`lower`／`accessory`），v7–v8 依上述遷移。v1–v6 讀為空背包／無裝備；未知但合法的舊物品 ID 保留，退役裝備不給加成，仍可卸下回背包。
- 出發複製背包與裝備；本場原料／成品在勝利、失敗或放棄時保留，結算以**最終背包取代出發背包**，不重複加回已消耗物品。存檔寫入成功才更換大廳狀態，寫入失敗可原樣重試；不存星球中途狀態。
- Q-W21 的季節食材、季節物種與服裝外觀套用仍屬各自項目；十種寶石對應進化珠寶仍待 P3-27。本系統的無屬性寶石原礦不代替該對應表。

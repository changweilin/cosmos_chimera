# 多人模式

## 模式
| 模式 | 人數 | 說明 |
|---|---|---|
| 單機 | 1 | 主要體驗，完整內容 |
| 合作 | 2–4 | 同一顆星球一起探索、打 BOSS；收服/掉落分配 → Q-N1 |
| 對抗 | 2–4 | 宙獸隊伍對戰（競技場星球或野外 PvP）→ Q-N2 |

## 連線方式
- **區域網路**：主機兼玩家（listen server），LAN 廣播探索房間。
- **玩家自建伺服器**：同一程式的 headless dedicated server build，直連 IP:port。
- 不依賴官方雲端服務（Relay/大廳）；日後可選配。

## 同步原則（技術細節見 `architecture/netcode.md`）
- 主機權威：戰鬥結算、掉落、收服由主機計算。
- 星球不傳地形：只傳 `seed + PlanetType + GeneratorVersion`，各端本地生成 → 生成必須可重現。
- 版本不符（GeneratorVersion / 資料雜湊）直接拒絕加入。

## 防作弊
單機與私人伺服器為主，不做反作弊；只確保主機權威避免客戶端直接改血量。

# 角色（玩家與 NPC）

玩家角色不直接攻擊（`combat.md`），角色的存在感來自外觀、動作與跟宙獸的互動。用途（Q-A1）：角色概念同時作為玩家可選的預設外觀與 NPC；玩家可捏臉（在預設外觀上調整，範圍見〈捏臉範圍〉）。

## 設計概念維度
| 維度 | 規則 |
|---|---|
| 人種 | 東亞 / 白人 / 各地原住民 / 其他，預設**各 25%** 加權隨機；原住民與「其他」再細分地區 |
| 性別 | 男 / 女（預設各 50%）；中性外觀為可選項，預設權重 0 |
| 年齡 | **青少年（13–19）佔 50%**；其餘：兒童 10%、青年 25%、中年 10%、長者 5% |
| 性格 / 風格 / 興趣 / 喜好 / 厭惡 | 各自從選項池抽取（性格 2、興趣 2、喜好 2、厭惡 2） |
| 定位 | 玩家角色預設、隊友 NPC、大廳 NPC、星球原住民 NPC、對手 |
| 慣用收服道具 | 符籙卡片 / 琉璃珠 / 魔術方塊（影響道具外觀與投擲動作，見 `lobby-meta.md#收服道具`） |

選項池與權重的唯一來源：`../cosmos_chimera_forge/catalog.js`。
資料格式唯一規範：`Data/schemas/character.schema.json`。

## 捏臉範圍
比照主流角色創建（預設外觀起手＋滑桿微調）：

| 分類 | 可調項目 |
|---|---|
| 起點 | 從預設外觀（本表上方概念）挑一個再調整；可「隨機化」與「重置」 |
| 臉型 | 臉寬、下顎、下巴、顴骨、臉長 |
| 眼 | 大小、間距、高低、眼角角度、瞳色、瞳孔大小 |
| 眉／鼻／嘴／耳 | 眉形與粗細、鼻樑／鼻頭／鼻寬、唇厚／嘴寬／嘴角、耳大小與角度 |
| 髮 | 髮型（含前髮／後髮／髮飾分層）、髮色、挑染 |
| 膚 | 膚色、雀斑／痣／疤痕貼花、妝容（唇／眼影／腮紅）、紋身與面紋（需通過 `sensitivity` 審核的圖樣庫） |
| 體型 | 身高與體格在該角色年齡層允許範圍內的滑桿；不跨年齡層 |

- **不可改**：年齡層、種族預設標籤、性別標籤（僅影響資料分類；外觀滑桿不受限制，不做性別鎖定）。
- 實作約束：以 blendshape／骨骼縮放＋貼花層實作，捏臉結果存成一組滑桿值（整數千分比），隨存檔與連線同步；不存網格。
- 玩家角色與 NPC 共用同一套外觀資料結構，NPC 只是固定滑桿值。

## 數據格式與跨專案共同維護
- **格式一致性**：角色數據結構與 `cosmos_chimera_forge`（立繪鍛造台 `catalog.js`、`tasks.js` 與交付包 `concept.json`）完全相同。
- **規範定義**：`Data/schemas/character.schema.json`（定義 `id`、姓名中英、`role`、`ethnicity`、`gender`、`age_band`、`age`、`height_cm`、`personality`、`vessel`、`biography` 等標準欄位）。
- **共同維護協定**：
  1. `cosmos_chimera`（本專案）與 `cosmos_chimera_forge` 雙向同步 `Data/schemas/`、`Data/_incoming/` 及基礎資料。
  2. 任何一邊改動角色或宙獸資料／Schema，必須在同一次作業中同步至另一專案。
  3. 驗證標準：兩邊執行 `tools/validate-data` 皆須為 0 error，且 forge 跑 `python gen_designed.py` 產出正常。

## 文化呈現準則
- 原住民與各族裔服飾取**當代與傳統融合**的意象，不做刻板化（羽毛頭飾＝印第安人、斗笠＝亞洲人之類）的符號堆疊。
- 涉及特定族群的神聖紋樣、儀式服飾：標記 `sensitivity: review`，人工審核後才採用。

## 動作清單
完整 clip ID、幀數與事件見 `art-asset-pipeline.md#動作`。涵蓋：移動（待機/走/跑/潛行/翻滾閃避/跳躍）、格擋、命令（指向/攻擊/收回）、召喚與收回宙獸、使用道具（自身/他者）、佈署場地、開背包、對話、撫摸宙獸（依 XS/S/M/L/XL 體型）、投擲三類收服道具、受擊/倒地/起身、勝利/戰敗。

## <a id="路人-npc"></a>路人 NPC（P3-18；規則層 `WorldGen/PopulacePlanner`，表現層 `Bootstrap/Demo/NpcMeshes`、`PopulaceView`；數值暫定）
- **規則層實體**：有碰撞（半徑 0.4 m，擋角色與宙獸）、多人同步（同 seed 各客戶端相同）。站在有人居住的聚落（部落／小鎮／都市／城邦／村落）建築門前；遺跡與巢穴無人。道路上與野外營地未做。
- 聚落種類只代表**規模**，不綁定地區與時代風格。
- 路人不套用玩家預設的人種與年齡權重。

### 種族
人類、精靈、矮人、哥布林、獸人、鳥人、魚人、蜥蜴人、龍人、殭屍、骷髏、狼人、吸血鬼、天使、惡魔（`NpcRace`，只增不改）；規劃新增**巨人、食人妖、機器人（多種樣態）**。

### 人數與互動
- **人數**：每棟建築門前 1–6 人（帳篷 1–2、民居 1–3、大廳 3–6、塔 1–2），單一聚落上限 60 人。
- **互動**：對話（閒聊／世界觀）、交易（商人）、治療昏厥宙獸（治療師，`combat.md`）、委託任務、指路（揭露地圖）。
- **受擊**：招式打到路人時**會受傷逃跑**。

| 層 | 抽法 |
|---|---|
| 星球 | seed 抽主種族與副種族（不同）；權重 = 基礎（人類 20，其餘 3–10）× 星球類型加成（翠綠：精靈、狼人 ×2；熔岩：龍人、惡魔 ×3，獸人、蜥蜴人 ×2；冰晶：矮人、狼人、骷髏 ×2；風暴：鳥人、天使 ×3，魚人 ×2；晶礦：矮人 ×3，哥布林、骷髏 ×2；晨昏：吸血鬼 ×3，殭屍、惡魔、精靈 ×2） |
| 聚落 | 60 % 沿用星球的主／副；25 % 副種族改為區域主題的種族（森林→精靈、河岸與海岸→魚人、高地→鳥人、隕坑→龍人、冰棚→狼人、峽谷→矮人、遺跡→骷髏），主題無對應時另抽；15 % 是飛地（副種族或另一種族為主，星球主種族為副）。副種族佔比 = 星球值（10–40 %）＋常態偏移；其他種族 3–12 %＋常態偏移 |
| 個人 | 依聚落佔比擲一次：主／副／其他（其他＝全種族依星球權重再抽） |

### 職業
無（兒童與無業）、農夫、獵人／採集者、漁夫、礦工、工匠、商人、守衛、學者、祭司、治療師、搬運工、藝人、領袖（`NpcRole`）。權重依聚落種類（部落重採獵、村落重農、都市重工商、城邦重守衛與學者）× 區域主題（海岸漁夫 ×3、峽谷與隕坑礦工 ×3、森林獵人 ×3…）× 種族傾向（各種族兩個職業 ×2，不設禁止）。兒童一律無職業。職業是規則層欄位；穿什麼由表現層依時代決定。

### 年齡與健康（有界常態）
抽樣一律用四個整數均勻亂數之和（Irwin–Hall，|z| ≤ 3.46σ，不經浮點）。
| 面向 | 聚落平均 | 每人偏移 | 外觀 |
|---|---|---|---|
| 年齡（佔該種族壽命的千分比） | 聚落種類基準（部落 360 … 村落 430）＋時代修正（原始 −40、未來 +40、廢土 −60）＋σ 40 | σ 170，夾在 40–980 | 兒童（< 16 %）身高 52–83 %、頭身比大；長者（> 72 %）灰髮、駝背、略矮 |
| 健康（千分比，只影響外觀） | 聚落種類基準（740–830）＋區域主題（隕坑 −60、遺跡 −80…）＋時代修正（未來 +80、廢土 −150）＋σ 50 | σ 130；中年 −40、長者 −120 | 膚色轉灰、駝背、繃帶 1–3 處（< 45 %）、拐杖（< 35 %，或長者 < 60 %） |
| 體型 | 種族基準（身高 1.12 m 哥布林 … 2.08 m 龍人、肩寬、粗細、手長、前傾） | 身高 σ 5 %、粗細 σ 10 % | 男女骨架差異；肚圍隨粗細 |

種族壽命（年）：人類 80、精靈 600、矮人 250、哥布林 45、獸人 60、鳥人 60、魚人 120、蜥蜴人 90、龍人 400、殭屍／骷髏／狼人 80、吸血鬼 900、天使 1000、惡魔 800。吸血鬼、天使、惡魔外觀不隨年齡變老。

### 外觀（表現層）
- 剪影由種族決定：耳形、獠牙、喙與羽冠、鰭、吻部與尾、角、蝙蝠翼／羽翼與光環、骨架、狼首與鬃毛、吸血鬼立領披風。
- 服裝沿用建築的風格軸（[settlement-structures.md](settlement-structures.md#建築造型)）：**時代**決定剪裁與材質（原始獸皮與骨飾、農耕束腰長衣、商貿泡袖與高筒靴、工業長外套與排扣、蒸汽龐克黃銅肩甲與護目鏡、未來貼身服與光帶、廢土補丁與圍巾），**地區**決定染色與招牌配件（翠綠披肩兜帽、熔岩斜肩帶與額帶、冰晶毛領與手套、風暴披風、晶礦腰帶與額飾、晨昏寬袖與腰燈）。
- 混搭：每人的借用比例 = 聚落混合比例＋常態偏移（σ 0.18）；上衣、下身、頭飾、招牌配件、配色各擲一次硬幣決定取主風格或借用風格；借用風格依聚落的第三風格佔比取副風格或第三風格。
- 職業道具：草帽與鋤、弓與箭筒、釣竿與魚簍、礦盔燈與十字鎬、圍裙與鎚、行囊、盔矛盾、書、發光法杖與聖帶、頭巾與藥包、肩上木箱、羽帽與魯特琴、披風與頭環。
- **美術與動作方針**：維持程序化人形並繼續精修；路人依職業做事（耕作、打鐵、站崗等，目前仍為靜態佔位網格，140 m 外不繪製）。
- 未定：`../open-questions.html` Q-A5（不死／魔族 NPC 定位）。

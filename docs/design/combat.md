# 戰鬥

即時動作戰鬥。探索中玩家操作角色（移動、翻滾、投擲收服、下指令）。**戰鬥中玩家直接操作主控宙獸的移動與出招**（Q-C55，取代 Q-C8「玩家只下指令」）：攝影機跟隨主控，角色只剩外觀、自動跟隨主控，不會被打、不能翻滾也不能投擲；支援宙獸仍由 AI 施招。輸出全部來自宙獸，場上同時最多 2 隻。出招鍵見 [controls.md](controls.md)。原本的四個指令（集火／自由／跟隨／撤退）改為**切換主控／切換支援模式（[支援模式](#支援模式)）／更換備援或道具（快捷輪盤，戰鬥不暫停）／回到角色**（按鍵見 controls.md）。**回到角色**＝收回在場宙獸、改操作角色，角色恢復探索規則（會被打、可翻滾、投擲仍要等戰鬥結束），直到脫戰。**瞄準**：前方類判定（front／line／sweep／cone、burst 以自身為中心）朝主控面向；瞄準點招（burst 目標點／arc／field）打鎖定目標，無鎖定時取面前最近的敵人。**戰敗＝上場池全部倒下**（已收服者保留）。**P2-17 接線前執行期仍是舊流程**（AI 施招、角色可被打）。回饋分級、格擋、地城氛圍與 BOSS 加強見 [combat-feel.md](combat-feel.md)。

## 傷害公式（係數是 tunable，放在 `Data/balance.json`）
比值、上下限與 `D = 0` 取上限見 `DerivedStats.AttackRatioPermille`；係數 `Data/balance.json#damage`。攻擊方的攻在施放被接受時凍結（同專精），目標的守在命中時讀取。

```
A       = move.polarity == yang ? attacker.陽攻 : attacker.陰攻
D       = move.polarity == yang ? target.陽守   : target.陰守
ratio   = clamp(A / D, ratio_min, ratio_max)          # 暫定 0.25 / 4；D = 0 時取 ratio_max
raw     = move.power × ratio × (1 + attacker.mastery[move.element] / 100)
damage  = raw × (1 − clamp(target.resist[move.element], −100, 100) / 100)
crit    → damage × crit_damage                        # 見〈暴擊〉
```
- `resist < 0` 表示弱點（受到更多傷害）；`resist = 100` 表示免疫。
- 沒有全域相剋表。攻守取自[六大能力值](creatures.md#六大能力值)，[等級](level-progression.md)縮放攻守，所以等級經由攻守比進入傷害；專精、主動技威力與抗性不隨等級縮放。
- 以比值計算：雙方同等級同預算時約 ×1，夾住避免極端偏科一擊必殺或完全打不動。
- 沒有六能力值的目標：**場景物件**攻守比固定 ×1（只看屬性、物質與生活技能加成，見 [destructibles.md#傷害](destructibles.md#傷害)）。
- <a id="玩家角色的守"></a>**玩家角色**沒有六能力值，陰守／陽守 = 底值 + 防具加值。底值依[玩家等級](level-progression.md#玩家等級) P 用與宙獸相同的等級縮放：`(100 × (P + 10) + 55) // 110`（LV1 為 10、LV100 為 100；100 = 成年宙獸平均守，`Data/balance.json#player.base_defense`）。防具（盾、上身、下身）可加陰守、陽守點數（[crafting.md#穿戴與數值](crafting.md#穿戴與數值)），沒穿防具時只有底值。
- 代價型（`self`／`ally`）用施放者的攻對承受者的守；完美格擋反傷用攻擊者自己的攻對自己的守（主動技反彈回施放者，同抗性的處理）。
- <a id="暴擊"></a>**暴擊**：命中擲骰成功後再擲暴擊（同一 `Pcg32` 戰鬥 stream，順序固定在命中之後；爆率 0 時不擲）；基礎爆率 5%、爆傷 150%（`Data/balance.json#crit`），`crit_rate_mod`／`crit_damage_mod` 以百分點加上（爆率夾 0–100%、爆傷 100–1000%），在施放被接受時凍結。打宙獸與玩家角色都會暴擊；不擲骰的 `self`／`ally` 主動技、完美格擋反傷與場景物件不暴擊。暴擊乘在公式傷害上，之後才套失衡加傷與格擋。
- 以 Int64 計算中間值，只在最後四捨五入（half up）；威力非零且非免疫的命中至少 1 點。`power` 表示域為 0..100000，有效專精為 0..1000；這是資料／API 契約上限，非平衡目標。P2-09 必須保證修正後專精符合此域，負值先歸零；疊加規則另由 P2-09 定義。

## CD
`effective_cd = max(cd_floor, move.cooldown_ms × f(速度))`，`f` 為遞減函數，`cd_floor` 防止極端速度值打破節奏。

## 命中與閃避
**兩段判定**（Q-C7 定案）：先做幾何命中（判定體/彈道碰到才算），碰到後再擲骰：
```
hit_chance = clamp(move.accuracy / 100 × (1 − target.evasion), hit_floor, 1)
```
- `target.evasion` 為全宙獸共同基礎值，只由技能與裝備提升，設上限（暫定 40%）；`accuracy_mod`（武器「命中」）以百分點加在 `move.accuracy` 上，可超過 100（上限 200）以抵銷閃避，施放時凍結。
- `hit_floor` 暫定 5%，讓任何幾何命中都有機會生效。
- 擲骰 miss 一定要有明顯回饋（「MISS」字樣、殘影閃避動畫、專屬音效），不然玩家會以為判定有 bug。
- 擲骰用主機端的 `Pcg32`（戰鬥用的 stream，跟生成用的分開），讓多人時結果由主機權威決定。
- 翻滾閃避是無敵幀，不走擲骰：探索中是玩家角色，戰鬥中是主控宙獸（[完美閃避](#完美閃避)）。

## 範圍/射程
`range = move.base_range_mm × g`，`g` 為全宙獸共同基礎倍率，只由技能與裝備提升；每招必填非負 Int32 毫米值，不從 `range_class` 查表。近戰主動技放大判定體積，遠程主動技延長射程。

初稿值：melee=2000、mid=12000、long=24000 mm，已逐招寫入初稿，之後可個別調整。`burst` 的數值表示爆發半徑；`origin` 只指定中心來源，目標點的選擇與施法距離判定屬 P2-04。`movement=dash` 時，數值表示突進的直線路徑長度，必須 1–36000（Q-C19：與遠程 36 m 上限一致，schema／importer／validate-data 同步檢查；幾何層 `ResolveDashEnd` 另以施放者半徑·π/4 為正確性界）。

## 召喚與輪替
- 上場池最多 4 隻，**同時最多 2 隻在場**（Q-C4 定案）；切換有共用冷卻（暫定 3 s），避免無限換手來躲傷害。
- Q-C11：兩隻在場時以「主控 / 支援」區分：玩家的指令只給主控，按鍵切換主控對象；規則見〈戰鬥 AI〉。
- 效能預算：4 人合作時場上最多 8 隻玩家宙獸 + 敵人，P2-10 的 AI 與 P6-04 的同步都以這個數量做壓力測試。
- 主力倒下 → 自動退場，不可在本場戰鬥中再上場（暫定）。
- <a id="收服時機"></a>收服一律等到戰鬥結束（Q-C55）：戰鬥中先被擊倒的野生宙獸躺在地上，等戰鬥結束後再投擲收服。玩家逃跑或戰敗時，倒地者留在原地直到所在區域卸載。BOSS 倒地後同樣留在原地，直到被收服或玩家離開其區域（取代 20 秒收服窗口；P2-17 接線前執行期仍是舊窗口）。
- <a id="收回與逃跑"></a>收回與逃跑（Q-C55）：戰鬥結束時自動收回在場宙獸；玩家也可隨時收回宙獸後逃跑，脫戰仍需離所有開戰野生 > 40 m（`DisengageRadiusM`）。
- 昏厥持續整場 run（D0-R1）：倒下的宙獸不會隨時間或脫戰恢復；恢復手段包含**消耗道具、NPC 治療、定點營火／泉水、隊友救援（互動）**。昏厥恢復道具可由野怪掉落、商店購買、任務獎勵取得，依取得地點分恢復量（矮行星 30%／行星 60%／超巨星 100%）；可在戰鬥中使用，但有施放時間、效果減半，冷卻 60 s（Q-C36 定案，D0 尚無此途徑）。
- P2-06 規則（實作 `Combat/Runtime/Model/Team.cs`）：
  - 6 主力在大廳定案、整場 run 不變；上場池 1–4 隻，只能在**非戰鬥中**從 6 主力重選，戰鬥中只在池內輪替。
  - 共用切換冷卻（`Data/balance.json#team.switch_cooldown_ms`）由**換手**或**主動收回**開始；開場召喚與倒下後補位不觸發冷卻，但冷卻進行中一樣不能召喚（否則「收回 + 召喚」等於免冷卻換手）。
  - 倒下的空位不自動補，由玩家手動召喚；池中全部倒下且場上無宙獸 → `IsWipedOut`（後續戰敗處理屬 P3/P6）。
- 玩家角色（`PlayerVitals.cs`，數值 `Data/balance.json#player`，暫定）：固定 HP 1000，不由能力值推導；翻滾 600 ms，其中前 400 ms 無敵，翻滾冷卻 800 ms（從開始算）。翻滾輸入鍵為 `Space`（另設計手把專用操作，Q-C33 定案）。無敵區間為半開 [開始, 開始+400)。HP 0 → Downed，不能翻滾。
- 副手不上場，只提供主動技 / 被動技 / 超載解鎖給主力（由副手的收服道具類別決定，見 `lobby-meta.md#收服道具`）；副手的裝備效果以 25% 換算給主力（[crafting.md](crafting.md)）。
- 超載（Q-C12 定案）：已解鎖的**僅成年**主力（暫定）可由**玩家指令**（暫定）在戰鬥中短暫進化為超載型態，**持續至戰鬥結束**、每場戰鬥一次（暫定），結束後回到原階段。

## 戰鬥 AI（P2-10；Q-C11、Q-C20、Q-C21）
- 指令（Q-C20）：`集火目標`（指定一個敵人）、`自由戰鬥`（預設）、`跟隨待命`、`撤退`。指令只給**主控**；**支援**不聽指令，依自身風格與[支援模式](#支援模式)戰鬥（Q-C11）。直接操作接線（P2-17）後主控改由玩家操作，這四個指令只剩 AI 主控（接線前與 PVP／測試）使用。
- <a id="支援模式"></a>支援模式（Q-C60；以「切換支援模式」循環）：**自由**（預設，取自己最近的敵人）／**集火**（取主控當下的目標，主控無目標時同自由）／**自由（猛攻）**／**集火（猛攻）**。猛攻＝不格擋、不閃躲（目前支援只有自動格擋會受影響）。實作：`Encounter.SetSupportMode`。
- 走位風格（Q-C21）：creature 資料逐階填 `ai_style`（schema 必填、封閉 enum），不由主動技推導。御三家：日=`keep_distance`、月=`flank`、星=`charge`。
  | ai_style | 站位（相對目標，沿大圓） |
  |---|---|
  | `keep_distance` 保距 | 站在最長敵對主動技可及距離 × `ai.keep_distance_permille` 處 |
  | `flank` 繞背 | 站在目標背後（-forward 切向）最短可及距離 × `ai.close_in_permille` 處 |
  | `charge` 突進 | 直接逼近到最短可及距離 × `ai.close_in_permille` |
  | `hold` 站樁 | 目標在最長可及距離 × `ai.hold_permille` 內就不動，否則逼近到該距離 |
- 目標：集火目標存活就打它；否則（支援）主控的目標；否則最近的存活敵人（同距取 id 小者）。集火目標倒下自動回到自由戰鬥。
- 施招：敵對招取可用（CD 好了）且目標中心在可及距離內、威力最高者（同威力取 slot 小者）。**治療／增益／控制招各有自己的觸發條件**（Q-C22 定案），不再永遠排在傷害招之後：治療以**不 HP 溢出**為原則施展、HP 低於 50% 一律施展，**脫戰也可補血**且**盟友 HP 低時也觸發**（ally 需隊友在射程內）。AI 只「選」，命中仍走 `MoveGeometry` → `Combatant`。
- 跟隨待命：離玩家超過 `ai.follow_leash_mm` 才往回走；只施放不必移動就打得到的主動技。撤退：走向玩家，不施招。
- 輸出是「目的地方向（單位向量）+ 目標 + 主動技 slot」；地面高度、尋路（Q-T1）、轉向與動畫屬表現層。可及距離是 AI 的**近似**射程門檻，不是命中判定：以施放者半徑量目標中心的地表距離，矩形取外接角落、aim-point 招取施放距離 + 半徑；目標與施放者高度差大時可能漏放或誤放，命中一律由 `MoveGeometry` 決定。
- 同一 tick 先算主控、再把主控的 `TargetId` 交給支援（整合層負責順序，避免支援讀到上一 tick 的目標）。跟隨待命不延續先前的集火目標，取最近存活敵人。
- <a id="野生領域"></a>野生領域（D0-E2／Q-C33，6 階領域梯度）：野生宙獸以自身位置為中心、依**個體習性**取領域距離；習性在生成時由棲位抽出（[生態規格](creature-ecology.md#習性)）。玩家角色或玩家宙獸進入距離內即開戰。目標為領域內**最近的入侵者**，玩家角色本人與玩家宙獸同等（同距取 id 小者）。玩家 HP 0（Downed）→ 本場 run 以失敗結算，已收服的個體保留。數值配置於 `Data/balance.json#ai.territory_mm`（Q-C35）：`avoidant` 迴避 0 m、`vigilant` 警戒 4 m、`tolerant` 耐受 8 m、`territorial` 護域 14 m、`aggressive` 攻擊 20 m、`dominant` 優勢 28 m（行為描述見生態規格）。
  - <a id="交戰上限"></a>**交戰上限 2 vs 2**（Q-C63）：同時與玩家方交戰的野生宙獸**每位玩家最多 2 隻**（對應玩家場上最多 2 隻）。已滿時，其他野生即使入侵者進入領域、被挑釁或被玩家主動技擊中也**不開戰**（受傷照算），只記為「想交戰」；交戰中的一隻倒下、被收服或脫戰後，從想交戰者中依離最近入侵者的距離遞補（同距取 id 小者）。想交戰者在入侵者全部離開脫戰距離時取消。**BOSS 戰不受此限**：BOSS 不佔名額，BOSS 交戰期間所有野生照原規則開戰。菁英照一般野生計算。加入**野生對抗**（[creature-ecology.md](creature-ecology.md#棲位食物鏈階級與野生對抗)）時改為 `1 玩家宙獸（可輪替）+ 1 野生盟友 vs 2 野生敵方` 的車輪戰，雙方待命個體依序遞補。
  - 實作（`Encounter`）：開戰後離所有入侵者 > 40 m 才脫戰（`DisengageRadiusM`，與習性無關）。玩家按**集火**可對 18 m（`ProvokeRadiusM`）內尚未開戰的最近野生宙獸開戰（`Provoke`，下一個 tick 生效）——這是與 `avoidant` 宙獸戰鬥的唯一方式。被玩家方主動技擊中（含場地）也會開戰。
  - <a id="遊蕩"></a>遊蕩（D0-W1，P3-31）：棲位決定來回週期／環狀週期／區域隨機／無限制隨機，以及速度、移動時間、停留時間的平均值與兩層標準差（個體間＋每次行動）；完整規則見 [creature-ecology.md](creature-ecology.md)。領域中心仍隨當下位置移動。亂數使用每隻個體獨立的遊蕩串流（由 spawn 序號衍生），不消耗戰鬥擲骰。
  - <a id="實體碰撞"></a>實體碰撞（D0-W2）：玩家角色、玩家宙獸與野生宙獸互為實體，不可互相穿過；以球面切平面上的圓形身體推開重疊（身體半徑依 `size_class`，Q-D2 定案：XS 0.2／S 0.4／M 0.7／L 1.1／XL 1.6 m，角色 0.35 m）。BOSS 的身體半徑與判定體同乘 1.5（見 planet-world.md〈目標與結束條件〉）。實作（`Encounter.Separate`）：半徑放 `Data/balance.json#ai.body_mm`（與命中判定球 `BodyRadiusFor` 分開）；每 tick 所有移動與施招之後，在場單位與角色兩兩沿大圓推開，依足跡面積反比分配（大的讓得少），依 unit id 順序掃 2 輪，決定性；角色那份由 `Encounter.PlayerPush` 回報、`RunSession` 套到角色。倒下／未上場單位不算實體。
  - <a id="只在陸地"></a>野生只在陸地：野生宙獸（含菁英、BOSS）不進入海面——遊蕩目的地、戰鬥／回家移動的每一步、實體推開都不會把野生放到海面上。玩家宙獸與角色不受此限。實作（`Encounter`）：海面由 `IEncounterSurface.IsSea` 判定；遊蕩目的地落海則以 (seed, 'W') 串流重抽，最多 `WanderSeaRetries` 次，皆落海則本次不出發、直接停頓；下一步落海則該步不移動（遊蕩路段就此結束並停頓）；推開後落海的野生保留原位，殘留重疊交給後續 tick。突進（dash）終點落海則照常判定命中、但不位移（SOL W-B2-SOL-02）。直線 steering 不繞行，海灣對岸的目標只能走到岸邊（tech-debt D0-E3）。出生點（`RunPlanner` v4，Q-D1-R1）：每個野生／菁英／BOSS 與降落點都在陸地上；區域內 8 次隨機取點與區域中心皆落海時，以固定環狀掃描取最近陸地（可能越過區域邊界）；陸地遮罩必須至少含一塊角半徑 `RunPlanner.MinLandCapRad`（0.02 rad）的完整陸地圓帽（比它窄的小島可能被掃描略過；Demo 的海只在 ≤ 6 個半角 0.45 rad 的模板內，遠超此條件），掃描找不到陸地則生成以 `ContractException` 失敗（所有 build）。
  - <a id="近身互動"></a>近身互動（D0-W3）：玩家角色靠近未開戰的野生宙獸，按互動鍵開啟選單：**觀察**（物種、階段、屬性、棲位、習性、等級）、**挑釁**（等同 `Provoke`，立即開戰，可對 `avoidant` 使用）、**撫摸**（安撫動作；目前無規則效果）。互動距離 3 m；撫摸無規則效果（Q-D2）。實作：`Encounter.NearestInteractable` 取身體邊緣間距 ≤ `InteractRadiusM`（3 m）的最近未開戰、未被挑釁野生（同距取小 id）；`RunSession` 互動鍵開選單（按鍵見 `controls.md`），選單用 DemoMenu 上下／確認／取消，開啟時角色停步、其他戰鬥指令不讀；觀察在選單內顯示資訊、挑釁＝`Provoke` 並鎖定該目標、撫摸只顯示提示；目標開戰、消失或離開 2× 互動距離時選單自動關閉。
  - <a id="指定目標"></a>指定攻擊目標（D0-W4）：保留集火鍵；新增目標切換（依距離循環 `ProvokeRadiusM` 內或已開戰的野生），鎖定目標顯示標記，主力依 `Focus` 攻擊該目標。對未開戰目標下集火仍會 `Provoke`。實作（`RunSession`）：切換鍵見 `controls.md`，依（距離, id）循環並在最後一個後回到最近；單按切換只鎖定、不開戰；已在集火指令下切換會立即改打新目標；集火鍵優先打鎖定目標，沒有鎖定才打最近並鎖定它；鎖定目標被擊倒、收服或離開候選範圍時自動解除；標記為目標頭上的黃色 ▼（未開戰時也顯示）。
  - 玩家角色受擊（Q-C35；Q-C55 改為**戰鬥中角色不會被打**，P2-17 接線時改執行期；戰敗改為上場池全倒）：閃避 0、抗性 0，只有命中率與翻滾無敵幀能擋；主動技附帶效果不作用在角色身上。BOSS 領域同樣依其個體習性。
- 規則層：`Combat/Runtime/Model/CombatAi.cs`，純函式、無配置記憶體、無亂數（同輸入同輸出，可在主機權威模擬）。

## 前搖與反應（規則層）<a id="前搖與反應"></a>
數值全部暫定，放 `Data/`（試玩後再調）。格擋與完美閃避的規則層已實作；輸入接線與表現屬 P2-17（直接操作）。
- <a id="前搖"></a>**前搖**：雙方**所有主動技**都有前搖，長度來自每招資料欄位 `windup_ms`（0..10000；BOSS ×1.5）。
  - 施放被接受即起算 CD 並觸發 `on_move_used`（修正值在此刻凍結，同〈被動技觸發〉）；前搖結束才做幾何命中與擲骰，近戰在該瞬間結算（投射物飛行屬表現層）。
  - 前搖期間施放者**可移動、轉向**；判定**在命中時追蹤目標**：瞄準點招取目標當下位置，前方類判定取施放者當下朝向。目標已失效時改朝施放者當下前方。
  - 同一單位同時只有一個前搖；前搖中不選新招。施放者倒下、被收回或**失衡**時前搖中止且**返還該招 CD**。
  - 初稿（Q-C53）：近戰 front／sweep／burst(caster) 300 ms、line／cone 450 ms、arc／burst(target) 600 ms、field 700 ms、self／ally 200 ms；之後逐招調整。
- <a id="失衡與擊退"></a>**失衡與擊退**（雙方宙獸，含 BOSS；玩家角色除外）：
  - 失衡槽容量 = 最大 HP × 30% ×（1 + 防具「失衡值」加成），每次命中累積實際傷害；最後一次受傷 3 s 後每秒回復容量的 20%。槽滿即**失衡 2 s**：無法施招（前搖中止並返還 CD），受到的傷害 +25%；結束後槽歸零。失衡期間不再累積。
  - 擊退：單次傷害達最大 HP 的 15%（combat-feel.md「重」級）時，沿攻擊者→目標方向推開 1.5 m；BOSS 不被擊退。擊退和其他位移一樣不進入海面（野生）與建築。
  - 完美閃避令攻擊者直接失衡（已在場、未失衡者）；完美格擋的反傷累積進攻擊者的失衡槽（見〈格擋〉）。
  - 數值：`Data/balance.json#stagger`。
- <a id="格擋"></a>**格擋**（Q-C56；數值 `Data/balance.json#block`）：
  - 主控宙獸由玩家**按住格擋鍵**持續格擋，放開結束；**支援宙獸自動格擋**：敵招前搖鎖定它為目標時開始，該招結算後放下；支援不會完美格擋。主控不替支援擋招。可擋近戰、投射物（line／arc）、範圍招（burst／field）；打向玩家角色的招不能被格擋。
  - 格擋中**不能施招、移速 50%**；主控舉起格擋會中止自己的前搖並返還 CD；支援自己在前搖中時不自動格擋。翻滾中與破防中不算格擋。
  - 一般格擋：基礎格擋值 35%（受到 65% 傷害，四捨五入，非零傷害至少 1）。持盾（左手裝盾）75%（`block.shield_permille`）。防具的**格擋減免率**直接加在這個值上；合計超過 100% 時一般格擋以 100% 計（不受傷），超出部分只加到完美格擋的反傷倍率。架勢條容量 = 最大 HP × 40%，累積被擋下那一擊的格擋前傷害；架勢填滿即**破防**：硬直 1.5 s（不能格擋、施招、移動），架勢歸零；最後一次格擋 2 s 後每秒回復容量 25%。
  - **完美格擋**：主控在敵招命中前 **150 ms 內放開**格擋鍵（含剛好 150 ms）；放得更早，這一擊照常吃滿傷害。完美格擋時自己照一般格擋受傷並累積架勢（Q-C59，暫定）；**反傷**＝被擋主動技原始傷害的 25%（＋格擋減免率超過 100% 的部分）（施放者凍結的專精、攻擊者自己的抗性結算，四捨五入，非零至少 1；`block.reflect_percent`），不擲骰、不觸發 `on_hit_taken`、不附帶效果，可擊倒攻擊者；反傷量同時累積進攻擊者的失衡槽。攻擊者已倒下或被收回（場地招）則不反傷。
  - 被動技日後可擴充格擋效果。按鍵見 [controls.md](controls.md)。
  - 實作：`Encounter.SetBlockHeld`；每 tick 開頭一次決定 `IsBlocking`（同一 tick 內所有命中看到相同狀態）；事件 `Blocked`／`PerfectBlock`／`Reflected`／`GuardBroken`；反傷 `Combatant.ReceiveReflect`。
- <a id="完美閃避"></a>**完美閃避**（Q-C55：戰鬥中由**主控宙獸翻滾**；數值 `Data/balance.json#creature_roll`，與角色翻滾相同）：翻滾 600 ms、前 400 ms 無敵（不擲骰，顯示 MISS）、冷卻 800 ms（從開始算）；失衡、破防中不能翻滾；**前搖中可以翻滾**，前搖中止並返還 CD（Q-C58）。翻滾開始後 150 ms 內被敵招碰到 → `PerfectDodge`，攻擊者失衡。
  - 位移（Q-C58：翻滾位移與跳躍高度都參考身高）：翻滾期間以等速沿輸入方向移動「身高 × `creature_roll.distance_height_permille`」（×1.5，暫定數值），無方向輸入時向後；翻滾中不轉向、不施招、不格擋，建築照常擋住。**身高**＝體型身體半徑（`ai.body_mm`，BOSS ×1.5）×2（XS 0.4／S 0.8／M 1.4／L 2.2／XL 3.2 m）。宙獸**跳躍高度**＝角色跳躍高度（1.2 m）× 宙獸身高 ÷ 角色身高（1.7 m），屬 P2-17。實作：`Encounter.TryRoll`。
- **PVP**：格擋、完美閃避、失衡／擊退照常生效；對方宙獸不能攻擊玩家角色。

## BOSS 階段（Q-C48）<a id="BOSS-階段"></a>
- BOSS 的 HP 上限為一般個體 ×3（[planet-world.md](planet-world.md) BOSS 戰數值）。
- HP 跌破各階段線（嚴格小於，與 `on_hp_below` 相同）即進入**狂暴**：移速與全屬性主動技 CD 獲得該階段的相對加成，與其他修正一起「先加總再乘」並套回上下限（〈效果疊加〉）。階段只升不降：被治療回線上也不解除；後一階段取代前一階段的數值，不疊加。
- 數值：`Data/balance.json#boss.enrage`（暫定）：HP < 66% 移速 +15%、CD −15%；HP < 33% 移速 +30%、CD −30%。CD 在施放被接受時計算，所以進入新階段前已在冷卻中的主動技不提早轉好。
- 實作：`Encounter.UpdateBossStage`（每次命中或代價傷害後檢查）、`EncounterUnit.BossStage`、`EffectBook.SetPhaseEffects`（獨立常駐層，可在戰鬥中替換）。表現層的 66／33% 衝擊波與咆哮沿用 combat-feel.md。

## 判定體（P2-04；全域預設，可逐招覆寫）
幾何使用域：只支援 R ≥ 320（Q-D1，`MoveGeometry.MinSupportedRadiusM`）；所有戰鬥座標須在距球心 R/2～2R 的殼層內；離錨點超過四分之一圓周（夾角 > 90°）的目標一律不命中，不論判定體多大。
尺寸預設在 `Data/balance.json#hit_volume`（鍵值見 [balance-keys.md](derived-stats/balance-keys.md)），目前 schema 沒有逐招覆寫欄位。實作：`Combat/Runtime/Model/HitVolume.cs`（`MoveGeometry`）。
| shape | 判定體 | 位置 | 長度 / 半徑 | 其他尺寸 |
|---|---|---|---|---|
| front | 矩形 | 施放者前方 | base_range | `front_width_mm` |
| line | 矩形 | 施放者前方 | base_range | `line_width_mm` |
| sweep / cone | 扇形 | 施放者，朝 forward | base_range | `sweep_angle_deg` / `cone_angle_deg`（全角） |
| burst caster | 圓 | 施放者 | base_range（半徑） | — |
| burst target | 圓 | 瞄準點，限制在 g(STR)×`target_cast_{mid,long}_mm` 內 | base_range（半徑，不受 STR） | 只能 mid/long |
| arc | 圓（落點） | 瞄準點，限制在射程 base_range 內 | `arc_landing_radius_mm` | 拋物線軌跡屬表現層 |
| field | 圓 | 瞄準點，限制在射程 base_range 內 | `field_radius_mm` | 壽命＝主動技 `field_duration_ms`，結算見〈場地〉 |
| self / ally | 無 / 隊友距離 ≤ 射程 | — | — | ally 不看高度 |

- **STR 縮放**：melee 所有尺寸（長、寬、高、半徑）乘 `MeleeLinearPermille`；mid/long 只把長度 / 射程 / 施法距離換成 `RangedDistanceMm`（含 36 m 上限），寬度、角度、AoE 半徑不變；dash 的路徑長度與位移固定等於 base_range，不縮放。小星球最後再依地平線收斂所有遠距距離與 dash（[星球射程上限](derived-stats.md#星球射程上限)）。
- **球面量測**：水平距離是以施放者半徑量的大圓距離（等距方位座標），高度是到球心距離的差（`height_mm/2` + 目標半徑內算命中）。R=640 時 36 m 外的地面比切平面低約 1 m，用平面判定會漏掉站在同一地面上的目標。
- **兩段命中**：`HitResolver.Resolve`；只有幾何碰到、且目標不在翻滾無敵幀時才擲骰，並且只用掉戰鬥 stream 的一次抽樣，讓各端依相同碰撞順序重播時保持同步。

## 主動技效果
`kind` 為 effect/both 的主動技，除 `heal_percent_max_hp`（瞬間）外必須填 `effect_duration_ms`（1..600000），表示效果在每個被命中目標上持續的時間；heal 與 damage 主動技不得填。作用對象由 `shape` 決定：`self` → 施放者、`ally` → 指定隊友、其他形狀 → 判定體命中的敵方目標。同一效果重複施加時的刷新/疊加規則由 P2-09 定。

主動技命名（P5-08 A5／Q-C26）：`light_aureole_halo` 改為 `light_crown_radiance`，舊 ID 退役，數值與效果沿用；其他主動技／被動技共用 cinder、tailwind、halo 詞根可保留，後續玩家顯示名需區分用詞。

## 場地（Q-C17）
- `shape: field` 的主動技必填 `field_duration_ms`（1..600000），其他形狀不得填。場地存在於 [放置, 放置+壽命)。
- 放置當下結算第一次，之後每 `Data/balance.json#field.tick_ms`（1000 ms）結算一次，共 ceil(壽命/間隔) 次；每次結算對判定體內每個目標各做一次完整主動技結算（命中擲骰＋傷害/效果），所以同一目標每次結算最多被作用一次。
- 規則層：`FieldTimeline`（`Combat/Runtime/Model/Effects.cs`）；模擬步進以 (上一步, 這一步] 計數，任何步長都不重複、不漏算。

## 效果疊加（P2-09）
- 疊加鍵＝（來源主動技/被動技 id, 效果序號），**與施放者無關**：兩隻同招的隊友不會讓同一增益翻倍；不同來源一律相加。
- 每個效果可在資料填 `max_stacks`（1..10，預設 1）。1＝重複施加只刷新時間；>1＝每次 +1 層直到上限，之後只刷新。刷新會重置整疊的剩餘時間（整疊一起消失）。治療是瞬間效果，不可填 `max_stacks`。
- 單位：`mastery_mod` / `resist_mod` 是百分點（直接加到專精/抗性）；`cd_mod_percent` / `evasion_mod_percent` / `move_speed_mod_percent` / `range_mod_percent` 是衍生值的**相對**百分比：同類全部先加總，倍率 100+Σ 夾在 `Data/balance.json#effects` 的 [10%, 300%]，只乘一次，再套回原本的上下限（閃避上限、射程 36 m 上限、CD 下限 250 ms），之後才套星球射程上限。先加總再乘，讓結果與施加順序無關（各端施加順序不保證一致）。
- 有效專精夾在 0..1000（傷害 API 域）；有效抗性夾在 ±100。CD 乘完後向上取整（與 P2-02 相同：CD 不得提早轉好）。
- `range_mod_percent` 只改「打多遠」：front/line/sweep/cone 的長度，以及瞄準點/友方主動技的施法距離；AoE 半徑、寬度、角度不變；dash 不受影響。
- 規則層：`EffectBook`（每個戰鬥單位一份）、`EffectMath`。

## 被動技觸發（P2-09）
- 持續判定（查詢當下測試，不存計時）：`always`；`on_hp_below{p}` 在 HP×100 < p×最大HP 時成立；`on_hp_above{p}` 在 HP×100 > p×最大HP 時成立（皆為嚴格不等式）。
- 事件觸發（開啟 `duration_ms` 視窗，依效果的 `max_stacks` 疊加/刷新）：`on_summon`＝每次上場（開場召喚與換手上場都算）；`on_ally_swap`＝**換手上場的那一隻**；`on_hit_taken{element|any}`＝命中確定（幾何＋擲骰）後，依主動技屬性比對；`on_move_used{element}`＝自己使用該屬性的主動技；`on_hp_cross_below{p, duration_ms}`＝HP 由 HP×100 ≥ p×最大HP 跌到 0 < HP×100 < p×最大HP 的那一刻（每次 HP 變動後以變動前後的值呼叫 `NotifyHpChanged`），**每場戰鬥最多一次**（`Clear` 重新武裝）；直接跌到 0 不觸發、也不消耗次數（不當復活用）。（Q-C18）。
- 事件觸發的治療效果立即回傳治療百分比給呼叫端；治療不可掛在持續觸發上。
- 結算順序（規則層 `Combat/Runtime/Model/Cast.cs` 的 `Combatant`）：
  - 主動技 CD 在施放被接受的瞬間起算；倒下或 CD 中的施放被拒絕且不觸發任何事件。
  - `on_move_used` 在施放時先觸發，**觸發它的這一招就吃到增益**（專精、CD、射程）；施放者的修正值在此刻凍結，之後每個目標與每次場地結算都用同一份。
  - 被命中：先以命中前的修正值擲骰、算傷害、扣血，之後才觸發 `on_hp_cross_below` / `on_hit_taken`，其增益**從下一擊起**生效。
  - HP 歸 0 的單位不再觸發任何被動技事件、不再被施加效果，也不能被治療（不當復活用）。
  - `self` / `ally` 形狀的主動技不擲骰、必定生效，也不消耗戰鬥亂數。若帶傷害（`damage` / `both`）就是**代價型**：傷害打在承受者（自己／隊友）身上，用施放者專精與承受者抗性照傷害公式計算，可以把承受者打倒（倒下後不再套效果）；這是 HP 變動所以可能觸發 `on_hp_cross_below`，但不是敵方命中，不觸發 `on_hit_taken`（ARGON 審查 K3）。
- 暫定（未定案，待 P2-10/P3 戰鬥流程確認）：收回宙獸時不清除身上的計時效果（以絕對時間到期）；戰鬥結束呼叫 `Clear`。

## 主動技形狀（動畫與特效分類用）
| 類別 | `range_class` | `shape` | 說明 |
|---|---|---|---|
| 近戰 | melee | `front` / `sweep` / `burst` | 正前方 / 橫掃 / 以自身為中心擴散 |
| 中遠距射擊 | mid, long | `line` / `cone` / `arc` | 直線 / 扇形 / 拋物線 |
| 目標點爆發 | mid, long | `burst` | 以目標點為中心的瞬間爆發 |
| 輔助 | — | `self` / `ally` | 對自身 / 對他者 |
| 佈署 | — | `field` | 在地面佈署持續場地 |

動作 clip 與特效以這個分類命名，見 `art-asset-pipeline.md`。

九種詞彙統一套用於 schema、GameData 與內容初稿。只有 `burst` 必須填 `origin=caster|target`，其他形狀不得填。位移獨立為可省略的 `movement=none|dash`（省略代表 none）；dash 只搭配 line，沿路徑突進並判定命中。幾何、移動、持續場地等處理器仍屬 P2-04，新增詞彙不代表這些處理器已完成。

150 招初稿遷移：近戰 line→front（10）、近戰 cone→sweep（13）、中遠距 line/cone 保留（52）、aoe→burst（37，近戰 caster／其餘 target）、dash→line＋movement=dash（38）。保留 ID、威力、CD、準確率與 range_class。

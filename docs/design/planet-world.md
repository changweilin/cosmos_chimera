# 星球世界生成

## 星球尺度
| 類型尺寸 | 半徑 R | 圓周 | 表面積 | 步行繞一圈（5 m/s） |
|---|---|---|---|---|
| 小行星 `asteroid` | 320 m | 2.0 km | 1.29 km² | ~6.7 分 |
| 衛星 `moon` | 640 m | 4.0 km | 5.15 km² | ~13.4 分 |
| 行星 `planet` | 960 m | 6.0 km | 11.6 km² | ~20.1 分 |
| 超巨星 `supergiant` | 1280 m | 8.0 km | 20.6 km² | ~26.8 分 |

> 表面積隨 R² 成長：超巨星內容量是小行星的 16 倍。內容密度預算以「每 km² 的 POI 數」定義，而非固定總數。
> 半徑 320／640／960／1280 m 四級（對應宙獸四型態：幼／少／成／超載）；小行星以 R=320 實際遊玩；戰鬥射程依地平線收斂（[星球射程上限](derived-stats.md#星球射程上限)，Q-D1）。

## <a id="boss-尺寸"></a>BOSS 決定星球尺寸（D0-B2）
| BOSS 型態 | 星球尺寸 |
|---|---|
| 一階（幼年 `juvenile`） | 小行星（320 m） |
| 二階（少年 `adolescent`） | 衛星（640 m） |
| 三階（成年 `adult`） | 行星（960 m） |
| 四階（超載） | 超巨星（1280 m）— 規則見 `combat.md`（P2-05 待接線） |

- 每顆星球先由 seed 決定 BOSS（物種＋階段），尺寸由上表推導；**星球類型不再決定尺寸**，只決定地貌與屬性偏好。
- 階段抽選：依[玩家等級](level-progression.md#玩家等級)解鎖，已解鎖階段**均等**抽：P&lt;20 只有幼年；P≥20 幼／少各 1/2；P≥35 幼／少／成各 1/3（`balance.json#progression.player.boss_stage_unlock_levels` = `[1, 20, 35]`，沿用進化門檻 H）。抽選用獨立亂數串流 `Pcg32(seed,'B')`（`WorldGen.BossDraw`），選星卡片抽定後帶入 run，不在降落時重抽。
- 型態封頂：該星球所有野生與菁英的型態**不高於 BOSS 階段**（`RunPlanner` v3）。
- 同 seed 在不同玩家等級可能抽到不同階段；分享 seed 時需一併分享階段（Q-M1）。
- 星海選星時，星球卡片顯示 BOSS 階段與星球尺寸，讓玩家依難度選星（P4-02）。
- 超載 BOSS 待 P2-05 超載實作接線後才加入抽選（Q-C12 規則已定案）；在此之前超巨星尺寸已定義（`PlanetSize.Supergiant`、R=1280）但抽不到，行星（成年）為最大。
- 地貌印章數（`TemplatePlanner.CountFor`）：小行星／衛星 4、行星／超巨星 6（面積密度待 P3 調整）。

## 生成管線（同 seed 必須可重現）
```
PlanetSeed + PlanetType + GeneratorVersion
  │
  ├─ 1. 骨架層 Macro      一般程序化地貌印章（草原、冰原、沙漠、沼澤、高山、森林…）→ 起伏度、海陸遮罩、河系
  ├─ 2. 生物群系 Biome     緯度×海拔×濕度 + 星球類型偏移（決定地貌形態與行動修正）
  ├─ 3. 地形 Heightfield   模板高程 + 噪聲細節，烘焙到 cube-sphere 區塊
  ├─ 4. 區域圖 Region      Voronoi 區域 → 區域連通圖（主路線、支線、祕境）
  ├─ 5. POI 佈置           聚落遺跡、進階地形地城入口、BOSS 巢穴、宙獸棲地、任務點
  ├─ 5b. 道路與建築        區域圖生成樹 → 主路／小徑；聚落建築（見〈道路與建築〉）
  ├─ 5c. 進階地形地城      僅 10 屬性進階地形為隨機程序化地城（地表封閉迷宮／獨立房間拼接並行）；一般地表開放無全域區域牆
  ├─ 6. 程序化室內/地城    暗黑式：手作房間模組 + 規則拼接 + 詞綴（用於進階地形獨立／地下地城）
  └─ 7. 散佈 Scatter       植被、岩石、水晶等障礙物（依地貌形態決定密度，如草原開闊、森林／高山密集）
```

## <a id="1-骨架層程序化地貌"></a>1. 骨架層：程序化地貌（ADR-0008）
- **植被、地貌、道路、建築全部由遊戲隨機生成**；不使用任何真實地圖資料（原 P3-01／P3-02 真實 DEM 模板已退役、資料與工具已刪除）。
- 地貌印章：`WorldGen.LandformSynth` 依地貌標籤合成 256×256 高程＋水系（海／河）格網，一顆星球 4／6 塊，以 gnomonic 投影貼到球面（`PlanetTemplates`），外緣 35 % 混入全球噪聲，所以沒有接縫斷崖。
- 選種：與星球類型地貌偏好相符的種類優先（`TemplatePlanner`，`Pcg32(seed,'T')`）；每塊印章各自以 seed＋序號生成，同星球兩塊同類地貌也不相同。
- 合成器只用整數運算，水系（決定「海」與生成點陸地判定）在所有機器與後端逐位元一致。

| 地貌標籤 | 分類／形態 | 生成器（暫定） | 障礙物密度 | 海／水系 |
|---|---|---|---|---|
| `grassland` | 開闊平原 | 平緩起伏草坡＋淺溪 | 低（開闊） | 無（偶有河） |
| `ice_field` | 開闊冰原 | 平緩冰穹＋3–5 座冰原島峰 | 低（開闊） | 無 |
| `desert` | 開闊沙丘 | 連綿沙丘＋乾涸河床 | 低（開闊） | 無 |
| `river_valley` | 開闊河谷 | 寬 U 型河谷＋主河 | 低–中 | 無（河） |
| `plateau` | 開闊台地 | 不規則台地＋陡崖 | 低–中 | 無 |
| `swamp` | 濕地泥沼 | 低窪盆地＋曲流淺灘 | 中 | 淺水／沼澤 |
| `archipelago` | 水域群島 | 低矮群島 | 低–中 | 多 |
| `fjord` | 水域峽灣 | 高地＋三條漸窄海灣 | 中 | 有 |
| `forest` | 多障礙林地 | 起伏丘陵＋蜿蜒河谷 | 高（密集樹岩） | 無（河） |

> **一般地貌 vs 進階地形區分**：一般地表僅出現一般隨機程序化地形（例如火山外圍 `volcano_foothills`、岩洞外圍 `cavern_outer`），**不**套用全域地牢牆；10 種屬性進階地形（如進階火山口 `volcano`、深層礦坑 `cave`）才是隨機程序化地城。
（形狀參數在 `LandformSynth`；調整時升 `LandformSynth.GeneratorVersion`。）

## <a id="地貌行動影響"></a>地貌對玩家與宙獸行動的影響（暫定）
不同地貌除地形起伏與障礙物密度外，亦對玩家與宙獸的移動、尋路及狀態產生修正：
- **移動速度與閃避／衝刺修正**：
  - 開闊平地（草原、台地）：移動與衝刺無懲罰，視野與動線暢通。
  - 泥沼／深沙（沼澤、沙漠）：移動速度降低、衝刺距離／冷卻受限（深沙／泥濘阻力）。
  - 冰原（`ice_field`）：地面低摩擦滑行、轉向慣性增加（急停／急轉較滑）。
- **障礙物與高低差阻擋**：
  - 多障礙地貌（森林、高山、峽谷）：密集樹岩與陡坡遮蔽視線與直線彈道，迫使玩家與宙獸尋路繞行（或破壞場景物件開路，見 [destructibles.md](destructibles.md)）。
- **環境狀態與冷卻／消耗影響**：
  - 極寒／高溫／雷暴等環境詞綴或地貌影響體力恢復、衝刺消耗或特定屬性招式冷卻（與區域詞綴、P3-04 Biome 聯動）。

## <a id="天氣影響"></a>天氣與對玩家／宙獸的影響（數值暫定）
天氣依**星球類型 × 當地地貌**決定權重基底，並以固定時段（預設 180 秒／段）隨時間動態輪替（`WorldGen.WeatherPlanner`，使用 `Pcg32(seed ^ hash(terrainId), 0x57454154 + slot)`，主機與客戶端結果一致）。天氣對**玩家**與**宙獸**採取不同規則：

- **玩家**：受能見度半徑、移動／衝刺速度倍率與翻滾冷卻倍率影響（極端天氣會增加翻滾冷卻）。
- **宙獸**：
  - **屬性適應**：若宙獸的專精（`mastery`）包含該天氣的增益屬性，則免疫該天氣的移速懲罰並改享適應移速加成；非適應宙獸則承受基礎移速修正。
  - **屬性招式聯動**：招式依屬性獲得天氣威力百分比修正（套用於 `DamageModel` 前的招式威力）與冷卻百分比修正（套用於 `EffectMath.EffectiveCooldownMs`）。
  - **野生領域與迷霧隱蔽（Q-C37 定案）**：暴雪／沙塵暴／迷霧縮小野生宙獸領域半徑；**迷霧**（`Fog`）屬天氣並啟用隱蔽效果——玩家與**己方宙獸皆受益**，在迷霧中**靜止或緩行**（≤ 2.0 m/s）時，野生偵測距離再減半。
  - **遠程彈道偏移**：強風／暴雪／沙塵暴會使中／遠距攻擊招式產生方向偏移角（`ProjectileDriftDegrees`）。

| 天氣 | 玩家（移速／衝刺／翻滾CD／視野） | 宙獸（基礎移速／適應移速／領域／彈道偏移） | 屬性聯動（威力 / CD） |
|---|---|---|---|
| `Clear` 晴朗 | 1.00 / 1.00 / 1.00 / 無限 | 1.00 / 1.00 / 100% / 0° | — |
| `Fog` 迷霧 | 0.95 / 0.95 / 1.00 / 18 m | 0.95 / 1.05 / 60%（緩行再減半） / 0° | 影 +15%/-10% · 光 -15%/+10% |
| `Rain` 降雨 | 0.96 / 0.94 / 1.00 / 45 m | 0.95 / 1.08 / 90% / 0° | 水 +20%/-15% · 木 +10%/-10% · 火 -20%/+15% |
| `Thunderstorm` 雷暴 | 0.92 / 0.90 / 1.05 / 35 m | 0.90 / 1.10 / 85% / 5° | 雷 +25%/-15% · 水 +15%/0% · 土 -10%/0% |
| `Blizzard` 暴雪 | 0.80 / 0.78 / 1.15 / 22 m | 0.82 / 1.10 / 70% / 8° | 冰 +25%/-15% · 火 -20%/+15% · 木 -15%/0% |

## <a id="道路與建築"></a>道路與建築（規則層；數值暫定）
- 規則層 `WorldGen.SettlementPlanner` → `RunLayout`，`Pcg32(seed,'S')`；只讀區域圖與陸地判定，不讀地形高度（ADR-0007）。表現層 `Bootstrap/Demo/SettlementView`：路面每 1 m 一列、橫向 5 欄逐點貼地（抬高 0.12 m），橋面平整且至少高出海平面 0.6 m，連續 2 列以上的橋段加石砌橋體（兩側護欄、每 10 m 一座橋墩與其間的拱、燈柱；無碰撞）；建築由 `Bootstrap/Demo/ArchitectureMeshes` 以程式生成網格（見下表），牆體維持規則層地塊與每層 3 m，只有屋簷、門廊、裝飾超出地塊（≤ 2.2 m），每棟一個不超出地塊的方盒碰撞體，底部埋到地塊最低角之下。散佈以 `WorldGen.LayoutClearance` 避開道路（半寬＋1.5 m）與建築（地塊外擴 1.5 m）。
- **建築造型**（表現層）：風格＝地區（星球類型）× 時代（seed 抽，整顆星球同一時代），每個聚落混入副風格並受區域主題微調，每棟建築的造型／新舊／毀損各自常態抽樣。細節與城牆、工廠、隧道、交通工具的規格見 [settlement-structures.md](settlement-structures.md)。
- **道路**＝區域圖的生成樹：主路線相鄰區域之間是主路（寬 4 m）；其餘每個區域以小徑（寬 2.5 m）接到較靠近降落點的鄰區。路線為大圓＋兩個低頻擺動，每 ≤ 8 m 一個頂點；經過海面的頂點標為橋。
- **聚落**：
  - **起始點一定是城鎮**（位於降落點，沿主路兩側展開；依星球尺寸決定可出現類型）：
    - 小行星（320 m）：僅 `Tribe`（部落）
    - 矮行星／衛星（640 m）：`Tribe`（部落）或 `Town`（小鎮）
    - 行星（960 m）：`Tribe`、`Town` 或 `City`（都市）
    - 超巨星（1280 m）：`Tribe`、`Town`、`City` 或 `CityState`（城邦）
  | 種類 | 位置 | 建築 |
  |---|---|---|
  | 部落 `Tribe` | 降落點（起始城鎮） | 大廳 1＋帳篷／民居 3–4 |
  | 小鎮 `Town` | 降落點（起始城鎮） | 大廳 1＋民居／塔 5–7 |
  | 都市 `City` | 降落點（起始城鎮） | 大廳 1＋塔 1＋民居／塔 7–10 |
  | 城邦 `CityState` | 降落點（起始城鎮） | 大廳 2＋塔 1＋民居／塔 10–13 |
  | 村落 `Village` | 主路線中段每個區域中心 | 大廳 1＋民居／塔 2–5 |
  | 遺跡 `Ruins` | 約 50 % 的支線區域中心 | 民居／塔 1–4 |
  | 巢穴 `Lair` | BOSS 生成點周圍半徑 16 m | 石柱 6 |
- 建築沿道路兩側排列（同側間距 9 m、退縮 2 m），面向道路；落在海上的地塊直接捨棄（不重抽，避免改動其他結果）。尺寸以公尺計、不隨星球半徑縮放。
- **建築與角色、宙獸碰撞**（使用者 2026-11-11 定案，取代同日「純裝飾」）：角色由建築的 Unity 碰撞體阻擋；宙獸在規則層 `Encounter` 以同一批地塊（`LayoutClearance.IsInsideBuilding`，外擴自身碰撞半徑）阻擋——移動、衝刺、推擠都不得由外進入地塊；撞牆時沿牆滑行（轉 45°／90°／135°，記住上次成功的一側），遊蕩目的地落在建築內則重抽。已在地塊內的單位（生成點落在地塊上）可自由走出。道路無碰撞。
- 建築與散佈物件可被攻擊、破壞，見 [destructibles.md](destructibles.md)。
- 未定（之後細化）：建築內部／互動、聚落與野生生成點的避讓、道路依坡度繞行、遠景粗 LOD 地形可能蓋住路面。

## <a id="進階地形地城"></a>進階地形地城（僅限 10 種屬性進階地形；數值暫定）
一般星球地表**不設全域區域邊界牆**，保留為開放式一般隨機程序化地形。**只有 10 個屬性的進階地形**才是隨機程序化地城，且於地表具有明顯邊界／入口標記，採兩種形態並行：
1. **地表封閉迷宮型**（`DungeonPlanner` → `DungeonLayout` ＋ `Planet.PlanetWalls`）：適用於地表型進階地形（如進階雨林、火山口、冰棚、迷宮等），在該進階地形區域內以高牆、隘口、捷徑、死路寶藏房與封印形成封閉迷宮。
2. **獨立室內／地下地城型**（P3-07 暗黑式房間模組＋拼接規則）：適用於室內或深層地下型進階地形（如機房／工廠／研究室、深海海溝、深層礦坑、高塔、太空設施、神廟），由地表入口進入後切換至獨立程序化房間地城。

> 原 `WorldGen.DungeonPlanner`（`Pcg32(seed,'G')`）與 `Planet.PlanetWalls`（高 12 m、底寬 14 m、頂寬 5 m，走廊／捷徑／死路寶藏房／BOSS 競技場鎖鑰／開放程度 0–100）保留作為地表封閉迷宮型進階地形與地城測試共用模組，不再預設套用於一般星球整顆地表。

- **寶藏房內容（Q-W3 定案）**：死路寶藏房放置**守關菁英＋可破壞容器**；玩家須**先打壞容器**取得獎勵（**進化素材／珠寶**），內容**依區域階級（Tier）分級**（目前表現層只放標記，獎勵實作待 P3-13 收尾）。
- 未定：牆的美術（目前是地形色的山脊）；遠景粗 LOD 下牆的鋸齒；捷徑出口遇上散佈物件。

## 2–5. 程序化層
- 區域圖保證：從降落點到 BOSS 至少一條主路線；每區域 1 種主題（遺跡、森林、洞窟…）。
- 暗黑式詞綴：區域可帶詞綴（例：「雷暴」→ 雷屬性招式 CD −15%、場景閃電），影響當場戰術。

### 進階地形與通行限制
進階地形需要獲得擁有特定屬性招式的宙獸並攜帶於隊伍中方可進入。特定星球等級／尺寸才可取得擁有該屬性地形招式的宙獸：

| 星球尺寸／階級 | 進階地形標籤（包含別名） | 必備招式屬性 | 對應 BGM |
|---|---|---|---|
| **Dwarf Planet 矮行星**（少年，R=640） | 機房／工廠／研究室 (`laboratory`, `factory`, `server_room`) | 金 (`Metal`) | `bgm_laboratory` |
| | 雨林 (`rainforest`, `jungle`) | 木 (`Wood`) | `bgm_rainforest` |
| | 深海 (`deep_sea`, `trench`) | 水 (`Water`) | `bgm_deep_sea` |
| | 火山／火山口 (`volcano`, `caldera`) | 火 (`Fire`) | `bgm_volcano` |
| | 礦坑／地底／洞穴 (`cave`, `mine`, `underground`) | 土 (`Earth`) | `bgm_cave` |
| **Planet 行星**（成年，R=960） | 冰棚／冰冠／永久凍土 (`ice_cap`, `permafrost`) | 冰 (`Ice`) | `bgm_ice_cap` |
| | 高塔／各式塔臺／摩天樓層 (`tower`, `spire`, `skyscraper`) | 雷 (`Thunder`) | `bgm_tower` |
| | 太空設施／浮空島 (`space`, `floating_island`, `space_facility`) | 風 (`Wind`) | `bgm_space` |
| **Supergiant 超巨星**（超載，R=1280） | 迷宮 (`labyrinth`, `maze`) | 影 (`Shadow`) | `bgm_labyrinth` |
| | 神廟 (`temple`, `shrine`) | 光 (`Light`) | `bgm_temple` |

- **基礎與環境 BGM 涵蓋**：
  - `bgm_mountain`：涵蓋高山、深山 (`deep_mountain`)、台地 (`plateau`)
  - `bgm_swamp`：涵蓋沼澤、湖泊 (`lake`)、濕地 (`wetland`)
  - `bgm_town`：城鎮與大廳背景音樂（`bgm_space` 屬進階風屬性太空地形，不作為大廳音樂）

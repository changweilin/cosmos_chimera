# 星球世界生成

## 星球尺度
| 類型尺寸 | 半徑 R | 圓周 | 表面積 | 步行繞一圈（5 m/s） |
|---|---|---|---|---|
| 小 | 320 m | 2.0 km | 1.29 km² | ~6.7 分 |
| 中 | 640 m | 4.0 km | 5.15 km² | ~13.4 分 |
| 大 | 1280 m | 8.0 km | 20.6 km² | ~26.8 分 |

> 表面積隨 R² 成長：大型星球內容量是小型的 16 倍。內容密度預算以「每 km² 的 POI 數」定義，而非固定總數。
> 半徑 320／640／1280 m 於 2026-11-10 由使用者確認（Q-D1 方案 b）；R=320 的戰鬥射程上限仍待定（Q-D1）。

## <a id="boss-尺寸"></a>BOSS 決定星球尺寸（2026-11-10 定案，D0-B2）
| BOSS 型態 | 星球尺寸 |
|---|---|
| 一階（幼年 `juvenile`） | 小 |
| 二階（少年 `adolescent`） | 中 |
| 三階（成年 `adult`）或超載 | 大 |

- 每顆星球先由 seed 決定 BOSS（物種＋階段），尺寸由上表推導；**星球類型不再決定尺寸**，只決定地貌與屬性偏好。
- 星海選星時，星球卡片顯示 BOSS 階段與星球尺寸，讓玩家依難度選星（P4-02）。
- 超載 BOSS 待 Q-C12 定案後才加入抽選；在此之前大型星球的 BOSS 一律成年。

## 生成管線（同 seed 必須可重現）
```
PlanetSeed + PlanetType + GeneratorVersion
  │
  ├─ 1. 骨架層 Macro      真實地理模板 → 大陸/海洋遮罩、山脊、主河系
  ├─ 2. 生物群系 Biome     緯度×海拔×濕度 + 星球類型偏移（冰、熔岩、雷暴…）
  ├─ 3. 地形 Heightfield   模板高程 + 噪聲細節，烘焙到 cube-sphere 區塊
  ├─ 4. 區域圖 Region      Voronoi 區域 → 區域連通圖（主路線、支線、祕境）
  ├─ 5. POI 佈置           聚落遺跡、地城入口、BOSS 巢穴、宙獸棲地、任務點
  ├─ 6. 程序化室內/地城    暗黑式：手作房間模組 + 規則拼接 + 詞綴
  └─ 7. 散佈 Scatter       植被、岩石、可互動物件（依 biome 表）
```

## 1. 真實世界地圖骨架
- **離線**從開放資料烘焙「地理模板包」，執行期不連網：
  - 高程：Copernicus GLO-30 / SRTM DEM
  - 土地覆蓋：ESA WorldCover；海陸/水深：ETOPO 2022；水系由 DEM 自算。**不使用 OSM**（2026-11-08 定案 Q-W1 方案 A，見 `docs/research/P3-01-map-data-licensing.md` §4.1；律師風險點於發行前確認）
- 模板 = 一塊真實區域（例：峽灣、群島、火山島、河口三角洲）縮放風格化後的遮罩與高程。一顆星球由 3–8 塊模板拼貼投影到球面，接縫以噪聲與山脈遮蔽。
- 授權：方案 A 資料只需署名（無 Share-Alike）；署名範本見 P3-01 報告。

## 2–5. 程序化層
- 區域圖保證：從降落點到 BOSS 至少一條主路線；每區域 1 種主題（遺跡、森林、洞窟…）。
- 暗黑式詞綴：區域可帶詞綴（例：「雷暴」→ 雷屬性招式 CD −15%、場景閃電），影響當場戰術。

## 目標與結束條件
- BOSS 戰數值（2026-11-10 定案，D0-R2）：BOSS 的 HP 上限 ×2；模型與 STR 判定體同乘 1.5（較易被命中、近戰觸及也更遠）。等級見 [level-progression.md#獎勵量](level-progression.md)（D0-X3）。
- 每顆星球：主任務鏈 + 1 個星球 BOSS（+ 隨機菁英）。完成任務或擊敗 BOSS → 收服機會或取得蛋（見 `lobby-meta.md`）。

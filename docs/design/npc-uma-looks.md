# 路人 NPC 外觀的 UMA 承載對照

路人 NPC 以 ADR-0014 的日系 UMA 自訂種族呈現，抽樣規則仍是 [characters.md#路人-npc](characters.md#路人-npc)；本檔只定義每個多樣性軸由 UMA 的什麼承載、以及保住多樣性的條件。決定與理由見 [ADR-0015](../decisions/ADR-0015-npc-uma-race.md)。

## 原則
- 規則層（`NpcSpec`、`NpcHeritage`、文化種子、有界常態抽樣）不變；純 C# 對照器把 `NpcSpec` 轉成 UMA 配方描述（DNA 值、slot id、色參數、掛骨部件）。
- 連續抽樣的軸用連續手段承載（DNA、blendshape 權重、shader 參數、程序化網格），不離散成預製變體。
- 顏色不烘進 atlas，一律走 shader 參數。
- DNA 上下限涵蓋 Irwin–Hall 抽樣極值（±3.46σ）。

## 種族覆蓋
| 種族 | 承載 |
|---|---|
| 人類、精靈、矮人、哥布林、獸人、吸血鬼、天使、惡魔 | 人形身體＋DNA＋blendshape＋剛性部件 |
| 鳥人、狼人、蜥蜴人、龍人、魚人 | 人形身體＋種族頭部 slot（吻長、頭鰭等 blendshape） |
| 殭屍 | 人形身體＋貼花（外露頭骨、縫線）＋blendshape（下顎鬆脫、缺耳） |
| 骷髏 | 獨立 UMA 種族（顱骨＋獨立下顎、張口、裂痕、眼火） |

## 替換門檻
三項全過才以 UMA 取代程序化人形，之後移除 `NpcMeshes` 的人體與頭部生成，只保留第 12、15（光環）、20 項的剛性部件：
1. **對照完整性**（EditMode）：每個外觀欄位都有對應；單獨改一欄，配方輸出必變。
2. **分布**（EditMode）：每顆星球取 1000 人，DNA 值不被上下限截斷；同聚落配方重複率低於門檻（數值暫定）。
3. **並排截圖**：同 seed 新舊對照（`COSMIMERA_CAPTURE`），使用者目視 15 族剪影可辨。

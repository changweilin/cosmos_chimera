# 打擊感與戰鬥節奏

讓「宙獸打中東西」有重量。一般 PVE／PVP 參考《寶可夢傳說 阿爾宙斯》（玩家走位、翻滾、投擲，宙獸出招）＋《曠野之息》（格擋、完美閃避、敵人失衡）；地城參考《暗黑破壞神》的壓迫氛圍；BOSS 戰的回饋比一般戰鬥更重。

規則（傷害、命中、CD、玩家不直接攻擊 Q-C8）見 [combat.md](combat.md)；本檔只定**回饋分級、表現層邊界、地城與 BOSS 的加強**。牽涉規則改動的部分列在〈未定〉，定案前不實作。

## 分層（Why：主機權威、4 人合作不能凍結全域時間）
- **表現層**：頓幀、震屏、受擊閃白、粒子、傷害數字、音效、手把震動、慢動作。只在本機播放，**不改變任何規則狀態或模擬時間**；連線時各端依收到的命中事件各自播放。可立即實作（P2-13）。
- **規則層**：失衡／擊退、格擋、招式前搖、完美閃避獎勵。會改變位置、傷害或時序，走主機權威與 `Pcg32` 戰鬥 stream，需先定案。
- 頓幀只凍結**攻擊者與受擊者**的 Animator／粒子時間，不凍結 `Time.timeScale`；慢動作只在單機啟用（連線時退化為對該單位的頓幀）。

## 命中回饋分級（表現層；數值暫定，寫在 `HitFeelTuning.Default`，人工試玩定稿後再決定是否外移 `Data/`）
分級依**單次命中傷害 ÷ 目標最大 HP**，再依結果覆寫：

| 級 | 條件 | 頓幀 | 震屏 | 其他 |
|---|---|---|---|---|
| MISS | 擲骰未中 | 0 | 0 | 既有 MISS 字樣、殘影、專屬音效（combat.md） |
| 免疫 | resist = 100 | 0 | 0 | 灰色「×0」（不需翻譯）、彈開音 |
| 輕 | < 5 % | 0 ms | 無 | 閃白 60 ms、小數字 |
| 中 | 5–15 % | 50 ms | 小 | 閃白 80 ms、受擊抖動 |
| 重 | ≥ 15 %，或命中弱點（resist < 0） | 90 ms | 中 | 數字放大＋弱點色、手把震動 |
| 擊倒 | 該擊使 HP 歸 0 | 150 ms | 大 | 擊倒野生時單機加 0.3 s 慢動作（30 %）；己方宙獸倒下只頓幀；爆散粒子 |

- **合併**：同一次施放命中多個目標只播一次頓幀（取最高級）；每個單位的頓幀以 token bucket 限額（容量 200 ms、每秒回補 200 ms，任一 1 秒最多 400 ms），避免 AoE 與場地連段卡頓。場地每跳結算最高只到「中」。
- **震屏**依受擊點與玩家距離衰減：10 m 內全額、40 m 外為 0。
- **玩家角色受擊**：畫面邊緣紅暈、手把震動、受擊動作；不頓幀（保持翻滾輸入手感）。
- **屬性辨識**：十屬性各有命中粒子與音色（接 P7-03）。
- **動畫對齊**：命中以規則層結算時刻為準；動作 clip 的 impact 幀對齊該時刻，必要時壓縮前搖，不延後結算。
- **無障礙**：設定提供「震屏強度」「閃白」開關（P7-07）。

## 格擋（曠野之息）— 細節待補
玩家角色已有格擋動作 clip（[characters.md](characters.md)）。由誰格擋、可擋什麼、完美格擋效果、按鍵，全部見 Q-C44；定案前不實作。

## 地城氛圍（暗黑破壞神；只影響進階地形地城與 P3-07 室內地城）
表現層，不改規則：
- **光影**：環境光壓低，以火把／晶簇／符文等點光源照明；畫面暗角；卡通描邊與色階保留，整體降飽和、偏冷或偏屬性色。一般地表不套用。
- **音場**：低頻環境音、遠處回音、宙獸腳步回響；進入菁英或 BOSS 房前音樂轉緊。
- **敵人**：菁英頭上顯示詞綴名牌（詞綴本身屬 P3-07）；擊倒時爆散成屬性粒子，掉落物彈跳噴灑並有落地音。
- **節奏**：房間入口有短暫視野收窄（霧／門扇），讓「推門 → 遇敵」成為節拍。

## BOSS 戰加強
表現層（P2-13 已做：×1.5、66／33 % 衝擊波、終結慢動作；其餘待做）：
- 開場：競技場封印關閉（已有）→ 名牌與頂部大血條（未做）→ BOSS 音樂（已有）。
- 命中回饋：頓幀與震屏 ×1.5（仍受單位頓幀限額）；BOSS 大招的地面預警圈要等 Q-C45 前搖。
- HP 66 %／33 %：衝擊波環＋頓幀震屏；咆哮音效與攝影機拉遠未做。
- 終結：最後一擊 0.6 s 慢動作＋攝影機環繞（單機）；連線時只播頓幀與爆散。

規則層（未定）：失衡槽（Q-C46）、階段轉換是否改變行為（Q-C48）。

## PVP
競技場模式本身仍是 Q-N2 暫定。打擊回饋與 PVE 共用分級；頓幀 ×0.5（避免對手感覺輸入延遲）。格擋、完美閃避、失衡是否在 PVP 生效與玩家角色可否被攻擊，見 Q-C49。

## <a id="建築造型"></a>建築造型（表現層 `Bootstrap/Demo/ArchitectureMeshes`；數值暫定）
純表現層：不進 `RunLayout` 雜湊，但同 (layout、星球類型、seed、區域主題) 各客戶端畫出相同聚落。牆體維持規則層地塊與每層 3 m，只有屋簷、門廊、裝飾超出地塊（≤ 2.2 m）。

### 風格軸
| 軸 | 決定方式 | API |
|---|---|---|
| 地區（主） | 星球類型 | `RegionFor` |
| 時代（主） | **seed 獨立抽，整顆星球同一時代**（七個有人居住的時代等機率）；遺跡與巢穴固定為遠古 | `PlanetStyleFor`、`SettlementEra` |
| 地區（副） | 星球層由 seed 抽另一個傳統；聚落所在**區域主題**有 60 % 機率改拉向該主題的傳統 | `PlanetStyleFor`、`MixFor` |
| 時代（副） | 主時代的相鄰時代（承先或啟後）；聚落有 30 % 機率改抽另一個相鄰時代 | 同上 |
| 混合比例 | 星球 0.15–0.45，聚落再加主題修正與常態偏移，上限 0.7 | `ArchMix.Weight` |

- 聚落種類不再決定時代，只決定建築數量／種類（planet-world.md）與保養程度（部落、村落較舊；都市、城邦較新）。
- 配色：聚落的主配色朝副配色混合（比例 × 0.7，仍以主風格為主）；每個聚落一組材質。

### 同一風格內的隨機性（每棟一次有界常態抽樣）
抽樣用四個均勻亂數之和（Irwin–Hall，|g| ≤ 3.47σ）：多數建築靠近聚落平均，少數明顯突出；有界所以不會突破地塊與外伸上限。
| 面向 | 聚落平均 | 每棟偏移 | 外觀 |
|---|---|---|---|
| 混合 | `ArchMix.Weight` | σ 0.18 | 比例類（坡度、曲線、出簷、石基、窗）內插；特徵類（木骨架、平頂、煙囪、外挑、管線、光帶…）逐項擲硬幣整個借用 |
| 造型 | 風格值 | 坡度 σ 12 %、出簷 σ 15 %、石基 σ 20 %、窗高 σ 7 % | 另有：近方形地塊屋脊方向二選一、20 % 截頭山牆、每面屋頂 0–3 個老虎窗、1–2 支煙囪 |
| 新舊 | 時代基準＋聚落種類＋主題（未來 0.1 … 廢土 0.8） | σ 0.15 | 風化面積擴大、色調變暗變灰並帶冷暖偏移、屋脊下垂、整棟傾斜（≤ 0.14 m）、百葉窗脫落、花箱減少 |
| 毀損 | 時代基準＋主題（未來 0.03 … 廢土 0.5） | σ 0.12 | 亮窗減少、窗戶封板、瓦片滑落→屋頂破洞、煙囪折斷、女兒牆與雉堞缺口、斜撐木 |

未定：遺跡依原時代區分殘骸造型；建築內部。

## <a id="城牆"></a>城牆（未實作，P3-14）
- 有牆的聚落：城邦（石牆）、小鎮（木柵）、村落（籬笆）、遺跡（殘牆）。都市、部落無牆。
- **規則層物件**：擋角色與宙獸，只能由城門進出（`SettlementPlanner` 產生牆段與城門、升 `GeneratorVersion`；`LayoutClearance` 與宙獸移動要認得城門）。
- 可被招式打壞（依物質與 HP，destructibles.md）。
- 未定：城門數量與位置、各種牆的高度／厚度／物質、遺跡殘牆的缺口比例、與 `PlanetWalls` 的共用程度。

## <a id="工廠"></a>工廠（未實作，P3-15）
兩者都要：
1. 聚落裡的新建築種類 `BuildingKind.Factory`：出現在都市；遺跡內為廢棄工廠。會改 `RunLayout` 快照（升 `GeneratorVersion`）。
2. 進階地形「機房／工廠／研究室」地城的地表入口（P3-07）。
- 未定：地塊尺寸、每個聚落的數量、物質權重（金屬／電線／晶片）。

## <a id="隧道"></a>隧道（未實作，P3-16；依賴 P3-07）
- 做法：獨立室內場景，洞口傳送（與 P3-07 獨立房間地城同一套場景切換）；不改 ADR-0001 的高度場地形。
- 出現條件：依地貌標籤（高山、峽谷）。
- 未定：每顆星球的數量、隧道內容（純通道或含遭遇）、宙獸與多人同步的傳送規則。

## <a id="交通工具"></a>交通工具（未實作，P3-17）
- 性質：沿道路移動的 NPC 載具（規則層路徑與碰撞），可被打壞、掉素材。玩家不可搭乘。
- 種類：獸拉車／雪橇、船／木筏、礦車／軌道、蒸汽車／火車、飛艇／熱氣球。
- 未定：各種類對應的時代與地區、速度與數量、被打壞後是否重生、對 NPC 的後果、船與飛艇的路徑（道路以外）。

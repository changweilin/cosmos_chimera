# 可破壞場景物件

星球上所有場景物件——建築、樹、灌木、草、岩石、可互動物件——都能被攻擊。結果取決於招式屬性、物件的物質與質量：木屋會燒成焦炭、岩石會碎、輕物件會被打飛。被破壞的物件會依物質機率性掉落屬性素材。參考作是薩爾達傳說（曠野之息）的「化學引擎」：規則少、組合多。

## 範圍
- **可破壞**：建築（`RunLayout` 地塊，每棟一個物件）、散佈物件（植被、岩石、互動物件）、地上未拾取的素材（光／影除外）。
- **不可破壞**：地形（不挖洞、不變形）、道路、海面。

## 誰能打（Q-C8 不變）
- 玩家角色仍不直接攻擊。物件只會被**宙獸招式**擊中。
- 招式判定體（`MoveGeometry`）掃到的物件全部結算，所以範圍招會波及路過的樹、牆與地上的素材。
- 玩家可以把物件設為目標：目標切換（Q／LB）的候選加入 `ProvokeRadiusM` 內的物件，集火鍵對鎖定的物件下達集火；主控照〈戰鬥 AI〉走位與選招，把物件當成不會動的目標。
- 戰鬥 AI **不會**自己選物件當目標；支援宙獸也不跟主控打物件，照常打敵人。
- 打物件不觸發野生宙獸的 `Provoke`；野生宙獸的招式也會波及物件。

## 碰撞
| 物件 | 角色 | 宙獸 |
|---|---|---|
| 建築、樹、灌木、岩石（完整時） | 擋（Unity 碰撞體） | 擋（規則層 `Encounter` 阻擋地塊，規則同 planet-world.md〈道路與建築〉） |
| 草、迷霧 | 不擋；在裡面**靜止或緩行**時有隱蔽效果（迷霧屬天氣，領域縮小＋緩行再減半，見 [planet-world.md#天氣影響](planet-world.md#天氣影響)） | 不擋 |
| 被打飛的物件、碎片、地上的素材（剛體） | 互相碰撞、推擠 | 不擋；宙獸走過會把它們推開 |
| 光／影素材 | 不碰撞 | 不碰撞 |

- 物件破壞後，它的阻擋地塊從 `Encounter` 移除，角色碰撞體也移除。
- 樹、灌木、岩石的阻擋地塊以樹幹／岩體半徑為準（不是樹冠）。

## 傷害
- 用同一條傷害公式（combat.md〈傷害公式〉）：攻擊方的專精照算，物件的抗性由物質決定。
- 物件**不擲骰**：物件不會動也不會閃，幾何命中就生效，不消耗戰鬥亂數串流（以免改變戰鬥擲骰的順序）。
- 物件沒有特性與效果簿；招式附帶的效果（增益、減益）不作用在物件上，只有下面〈物質反應〉的狀態。
- HP 0 → 物件破壞（〈破壞與掉落〉）。

## 物質（數值暫定，放 `Data/env-materials/*.json`）
每個物件由一種物質構成（建築由多種物質組成，見〈建築的組成〉）；`質量 = 密度 × 體積`，`HP = 物質基礎 HP × 體積`。每種物質對應一個屬性，決定破壞時掉哪個屬性的素材。

| 物質 | 例子 | 對應屬性 | 可燃 | 導電 | 易碎 | 不透光 | 密度 |
|---|---|---|---|---|---|---|---|
| `metal` 金屬 | 礦柱、金屬零件 | 金 | 否 | 是 | 否 | 高 | 極高 |
| `wire` 電線 | 建築配線 | 雷 | 否 | 是 | 否 | 中 | 高 |
| `chip` 晶片 | 機械、遺跡裝置 | 雷 | 否 | 是 | 是 | 高 | 中 |
| `wood` 木材 | 樹、民居、大廳 | 木 | 是 | 否 | 否 | 高 | 中 |
| `plant` 草木 | 草、灌木、樹葉 | 木 | 是（快） | 否 | 否 | 中 | 低 |
| `sap` 汁液 | 樹液囊、多汁植物 | 木 | 否 | 否 | 否 | 低 | 中 |
| `pectin` 果膠 | 果實、膠狀植物 | 水 | 否 | 否 | 否 | 低 | 中 |
| `kerosene` 煤油 | 油桶、燈油罐 | 火 | 是（爆燃） | 否 | 否 | 中 | 中 |

| `ice` 冰 | 冰原物件 | 冰 | 否 | 否 | 是 | 低 | 中 |
| `glass` 玻璃 | 窗、溫室 | 冰 | 否 | 否 | 是 | 極低 | 中 |

- 影屬性沒有對應物質，只來自夜間的〈影素材〉規則。
- 抗性：可燃物火弱、導電物雷弱、易碎物土／金弱、冰與玻璃火弱；其餘逐物質填表。
- 散佈物件的物質由 biome 散佈表指定。

## 物質反應（第一版：只作用在被擊中的那一個物件）
| 招式屬性 | 條件 | 反應 |
|---|---|---|
| 火 | 可燃 | **點燃**：持續燃燒，每秒扣固定比例 HP，燒完破壞；水、冰招式熄火。煤油被點燃時立刻爆燃（自身破壞） |
| 火 | 冰 | **融化**：傷害加成 |
| 冰 | 非冰、非玻璃 | **凍結**：一段時間內變成易碎 |
| 土、金 | 易碎（含凍結中） | **粉碎**：傷害加倍 |
| 雷 | 導電 | 傷害加成（暫定 ×1.5） |
| 風 | — | 衝量加倍（輕物件被吹飛） |
| 水 | 燃燒中 | 熄火 |

- 反應的倍率、時間、比例放 `Data/env-materials`，數值暫定。
- **延後到 P5**（combat.md〈屬性 × 環境互動〉）：火勢在相鄰可燃物之間蔓延、雷沿金屬／水傳導到附近單位、冰凍結水面成可走的路、煤油爆燃波及周圍。

## 物理（ADR-0009）
- 物件的運動用 **Unity 剛體物理**。重力自己加：每個剛體每個物理步施加指向星球中心的力（方向取 `PlanetFrame` 的當地 up 反向），`Physics.gravity` 設為零。
- 物件平常是靜態的（不建剛體）；**第一次被擊中才喚醒**，換成剛體。這讓數千個散佈物件不必常駐剛體。
- 被擊中時施加衝量：方向＝從施放者指向物件（沿切平面，略帶向上分量），大小 ∝ 招式威力；質量越大，被推得越少。超過門檻的重物件只受傷、不移動（例：整棟大廳、巨岩）。
- 宙獸的表現層帶運動學碰撞體，走過時推開剛體；規則層不讀剛體結果，宙獸不會被它們擋住或打傷。

## 破壞與掉落
破壞時物件換成碎片。每塊碎片是一般碎片（休眠一段時間後消失）或**素材**（留在地上等玩家拾取），由掉落擲骰決定。所有擲骰都用主機的掉落亂數串流（與生成、戰鬥串流分開）。

### 素材就是進化素材
- 物件掉的素材與擊倒野生掉的進化素材是**同一種**（creatures.md〈進化〉）：拾取後進大廳共用庫存，run 結束時帶回。
- 一般素材為 tier 1；**珠寶**為該屬性的 tier 3（十種屬性各一種珠寶，極稀有）。
- 拾取方式待 Q-M6。多人時的分配依 Q-N1。

### 掉落機率
- 每個被破壞的物件擲一次素材掉落；**體積越大，機率越高**（`機率 = clamp(基礎 + 每 m³ 加成 × 體積, 0, 上限)`，數值暫定）。成功時屬性依物件的物質決定：
  - 單一物質物件 → 該物質的對應屬性。
  - 由反應破壞的物件 → 轉換後的屬性：可燃物燒盡 → **焦炭**（火）；冰被火融化 → 水；其餘不轉換。
  - 建築 → 從建築的組成物質中依權重抽一種（〈建築的組成〉）。
- 珠寶另擲一次，同樣隨體積增加但上限極低；屬性與上面相同。
- 掉落的素材從碎片中選一塊替換，所以素材出現在物件倒塌的位置。

### 建築的組成（權重暫定）
| 建築 | 組成物質 |
|---|---|
| 帳篷 | 布、木材 |
| 民居 | 木材、石材、玻璃、電線 |
| 大廳 | 木材、石材、玻璃、電線、燈泡 |
| 塔 | 石材、金屬、電線、光纖、燈泡、晶片 |
| 石柱（巢穴） | 石材、晶體 |
| 遺跡（矮牆） | 石材、金屬、晶片、光纖 |

### <a id="影素材"></a>影素材（夜間）
- 物件在**夜間**（物件所在處太陽仰角 < 0）被破壞時，另擲一次影素材。
- 機率 ∝ **影子大小 × 不透光度**：影子大小取物件的投影面積（體積^(2/3)），不透光度取物質欄位（建築取組成物質的加權平均）。大而不透光的物件（石塔、巨岩）在夜裡最容易掉影素材；玻璃、冰幾乎不掉。

### 地上的素材
- 未拾取的素材是剛體，物理性質同其屬性的代表物質：金＝金屬、木＝木材、水＝果膠、火＝焦炭（可燃）、土＝石材、冰＝冰、風＝布、雷＝晶片；珠寶＝晶體但**不可破壞**。
- 可被招式擊中、推開、破壞，也照〈物質反應〉轉換：木素材被燒盡 → 變成火素材；冰素材被火融化 → 變成水素材。其他方式破壞素材則素材消失，**不再掉落**（不會無限分裂）。
- **光／影素材**：漂浮的光點／暗影，不碰撞、不可破壞，只能拾取。
- 地上的素材保留整場 run，不會自然消失。

## 狀態保留
- 每個物件有由生成結果決定的 id（建築＝`RunLayout` 序號，散佈＝區塊＋序號）；破壞過的 id 放在一個集合，區塊因 LOD 重建時查這個集合，不重新長出來。
- 地上素材的位置與種類、破壞集合都只保留在本場 run，不跨 run（Q-M4）。

## 連線（netcode.md〈權威劃分〉）
- 主機計算：物件 HP、反應、破壞、掉落、所有剛體運動、素材拾取。
- 客戶端：收到「物件喚醒／受傷／破壞／掉落／拾取」事件與喚醒中剛體的位姿，自己不模擬物件剛體；碎片休眠前的細節可只在本地播。
- 單機＝本地主機，走同一套程式。

## 實作分層
- **規則層（純 C#，EditMode 可測）**：物件表（id、位置、物質、體積、HP、狀態）、傷害與反應結算、破壞集合、掉落擲骰、影素材的夜間判定、樹／灌木／岩石的阻擋地塊。命中判定用 `MoveGeometry` 對物件位置與半徑，不用 Unity 碰撞體。散佈物件的位置必須由規則層產生（目前在表現層 `ScatterField`），宙獸才能被它們阻擋。
- **表現層（MonoBehaviour）**：剛體喚醒、球面重力、衝量、碎片、燃燒特效、素材外觀與拾取特效。規則層發出事件，表現層只執行。

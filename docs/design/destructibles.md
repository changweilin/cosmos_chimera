# 可破壞場景物件

星球上所有場景物件——建築、樹、草叢、岩石、可互動物件——都能被攻擊。結果取決於招式屬性、物件材質與質量：木屋會燒、岩石會碎、輕物件會被打飛。參考作是薩爾達傳說（曠野之息）的「化學引擎」：規則少、組合多。

## 範圍
- **可破壞**：建築（`RunLayout` 地塊，每棟一個物件）、散佈物件（植被、岩石、互動物件，`ScatterField`）。
- **不可破壞**：地形（不挖洞、不變形）、道路、海面。

## 誰能打（Q-C8 不變）
- 玩家角色仍不直接攻擊。物件只會被**宙獸招式**擊中。
- 招式判定體（`MoveGeometry`）掃到的物件全部結算，所以範圍招會波及路過的樹與牆。
- 玩家可以把物件設為目標：目標切換（Q／LB）的候選加入 `ProvokeRadiusM` 內的物件，集火鍵對鎖定的物件下達集火；主控照〈戰鬥 AI〉走位與選招，把物件當成不會動的目標。
- 戰鬥 AI **不會**自己選物件當目標；支援宙獸也不跟主控打物件，照常打敵人。
- 打物件不觸發野生宙獸的 `Provoke`；野生宙獸的招式也會波及物件。

## 傷害
- 用同一條傷害公式（combat.md〈傷害公式〉）：攻擊方的專精照算，物件的抗性由材質決定。
- 物件**不擲骰**：物件不會動也不會閃，幾何命中就生效，不消耗戰鬥亂數串流（以免改變戰鬥擲骰的順序）。
- 物件沒有特性與效果簿；招式附帶的效果（增益、減益）不作用在物件上，只有下面〈材質反應〉的狀態。
- HP 0 → 物件破壞（〈破壞〉）。

## 材質（數值暫定，放 `Data/env-materials/*.json`）
每個物件有一個材質和一個體積；`質量 = 密度 × 體積`。

| 材質 | 例子 | 抗性特徵 | 可燃 | 導電 | 易碎 | 密度 |
|---|---|---|---|---|---|---|
| `plant` 草木 | 草叢、灌木 | 火弱、土／金弱 | 是（快） | 否 | 否 | 低 |
| `wood` 木材 | 樹、民居、大廳 | 火弱、水抗 | 是 | 否 | 否 | 中 |
| `cloth` 布 | 帳篷 | 火極弱、風弱 | 是（快） | 否 | 否 | 極低 |
| `stone` 石材 | 岩石、塔、石柱、遺跡 | 土／金弱、火抗、木抗 | 否 | 否 | 凍結時 | 高 |
| `metal` 金屬 | 互動物件、礦柱 | 雷弱、火抗 | 否 | 是 | 否 | 極高 |
| `ice` 冰 | 冰原物件 | 火極弱、冰免疫 | 否 | 否 | 是 | 中 |
| `crystal` 晶體 | 晶礦星物件 | 土／金弱、光抗 | 否 | 否 | 是 | 中 |

- 散佈物件的材質由 biome 散佈表指定；建築的材質由建築種類決定（帳篷＝布，民居／大廳＝木，塔／石柱／遺跡＝石）。
- 物件 HP ＝ 材質基礎值 × 體積；大物件比較耐打。

## 材質反應（第一版：只作用在被擊中的那一個物件）
| 招式屬性 | 條件 | 反應 |
|---|---|---|
| 火 | 可燃 | **點燃**：持續燃燒，每秒扣固定比例 HP，燒完破壞並留下焦黑殘骸；水、冰招式熄火 |
| 冰 | 非冰材質 | **凍結**：一段時間內變成易碎 |
| 土、金 | 易碎（含凍結中） | **粉碎**：傷害加倍 |
| 雷 | 導電 | 傷害加成（暫定 ×1.5） |
| 風 | — | 衝量加倍（輕物件被吹飛） |
| 水 | 燃燒中 | 熄火 |

- 反應的倍率、時間、比例放 `Data/env-materials`，數值暫定。
- **延後到 P5**（combat.md〈屬性 × 環境互動〉）：火勢在相鄰可燃物之間蔓延、雷沿金屬／水傳導到附近單位、冰凍結水面成可走的路。

## 物理（ADR-0009）
- 物件的運動用 **Unity 剛體物理**。重力自己加：每個剛體每個物理步施加指向星球中心的力（方向取 `PlanetFrame` 的當地 up 反向），`Physics.gravity` 設為零。
- 物件平常是靜態的（不建剛體）；**第一次被擊中才喚醒**，換成剛體。這讓數千個散佈物件不必常駐剛體。
- 被擊中時施加衝量：方向＝從施放者指向物件（沿切平面，略帶向上分量），大小 ∝ 招式威力；質量越大，被推得越少。超過材質門檻的重物件只受傷、不移動（例：整棟大廳、巨岩）。
- 剛體穩定後休眠；休眠一段時間的碎片消失（只保留大型殘骸）。

## 破壞
- 破壞時物件換成預先切好的碎片（各自是剛體），建築倒塌成瓦礫；燃燒致死的物件換成焦黑殘骸。
- 建築破壞後，它的碰撞地塊從 `Encounter` 的阻擋集合移除，角色碰撞體也移除；宙獸可以穿過原地。
- 散佈物件維持現狀：**不阻擋**角色與宙獸移動（只是能被打）。
- 移動中的剛體（被打飛的物件、碎片）**不阻擋**規則層的宙獸，也不造成傷害（第一版）。角色由 Unity 碰撞體與它們互相推擠。
- 破壞狀態保留整場 run：每個物件有由生成結果決定的 id（建築＝`RunLayout` 序號，散佈＝區塊＋序號），破壞過的 id 放在一個集合；區塊因 LOD 重建時查這個集合，不重新長出來。不跨 run（Q-M4）。

## 掉落
- 部分物件破壞時擲一次掉落表（主機的掉落亂數串流，與生成、戰鬥串流分開）；掉落內容與機率待 Q-M6。
- 不掉進化素材：素材仍只在擊倒野生時給（Q-C32）。

## 連線（netcode.md〈權威劃分〉）
- 主機計算：物件 HP、反應、破壞、掉落、所有剛體運動。
- 客戶端：收到「物件喚醒／受傷／破壞」事件與喚醒中剛體的位姿，自己不模擬物件剛體；碎片的細節（休眠前的翻滾）可只在本地播。
- 單機＝本地主機，走同一套程式。

## 實作分層
- **規則層（純 C#，EditMode 可測）**：物件表（id、位置、材質、體積、HP、狀態）、傷害與反應結算、破壞集合、掉落擲骰。命中判定用 `MoveGeometry` 對物件位置與半徑，不用 Unity 碰撞體。
- **表現層（MonoBehaviour）**：剛體喚醒、球面重力、衝量、碎片、燃燒特效、殘骸。規則層發出事件，表現層只執行。

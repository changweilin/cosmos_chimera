# 大廳與 Meta 循環

## 循環
```
地球大廳 ──選星──▶ 生成星球(seed) ──▶ 探索/任務/BOSS ──▶ 收服/得蛋 ──▶ 返回地球
   ▲                                                                   │
   └──────────── 孵蛋、進化、隊伍編成、圖鑑更新 ◀───────────────────────┘
```

## 地球大廳
- 位置：地球上的觀測站（夜空開闊處）。玩家仰望星海，星座即星球類型；選擇後顯示：尺寸、主／副屬性與比例（見 `planet-world.md#星球屬性`）、詞綴預覽、推薦等級。
- 每次選擇都**隨機生成一顆新星球**（新 seed）。允許輸入／分享 seed 重玩同一顆星球（Q-M1）；因 BOSS 階段依玩家等級抽，分享時連同階段一起分享。
- 大廳功能：隊伍編成（6 主力 / 副手配置）、圖鑑、主動技表、被動技表、關係表、孵蛋所、多人房間；完成新手任務（[beginner-quest.md](beginner-quest.md)）進入主世界（大廳）後，可自由選擇**隨機世界**（星海選星）或**下一個主線劇情**。

## 收服與蛋
- 完成任務或擊敗 BOSS → 取得「收服機會」或「蛋」。
- 野外一般宙獸可收服：擊倒後投擲收服道具（Q-M2）。
- 蛋孵化條件（Q-M3 定案）：放入**孵化場**後累積進度——步行距離（超巨星繞一圈 = 100%）、戰鬥次數（1 次 = 2%）、戰勝 BOSS（+10%）。

## 收服道具
三個類別，玩家投擲道具收服宙獸；收服時使用的類別記錄在**該隻個體**上（存檔欄位 `vessel`，不是物種資料）。

| 類別 | ID | 作為主力 | 作為副手提供給主力 |
|---|---|---|---|
| 符籙卡片 | `talisman_card` | 無差別 | 一個主動技 |
| 琉璃珠 | `glass_bead` | 無差別 | 被動技 |
| 魔術方塊 | `magic_cube` | 無差別 | 解鎖主力自己的超載（見 `creatures.md#超載`），並提供副手物種的元素／抗性加成（`crafting.md#魔術方塊副手`） |

- 每隻副手只提供**一項**，由類別決定，不再由玩家二選一。
- 後期轉換類別（Q-C13 定案）：於**矮行星劇情完成後**由特定主動技／被動技解鎖（部分主動技／被動技兼具生活用途與進入特殊地形能力），消耗專精屬性素材；更換時**只更換功能，不更換外觀**（外觀維持收服／孵化時的原始器皿）。**蛋孵化的宙獸承襲親代類別**。
- 三類道具的投擲動作、收服特效各自不同（美術規格見 `art-asset-pipeline.md`）。

### 收服器皿分階
類別（上表）決定副手提供什麼；收服率另由器皿的**階**決定。**兩者並存**：每個基本器皿同時具備類別與階（例如「成年階琉璃珠」）；**進階（十屬性）器皿依屬性對應類別**。

- **基本器皿**分四階：幼年／少年／成年／超載。對野生宙獸，器皿階每高於目標型態一階 **+15** 個百分點、每低一階 **−25** 個百分點，加在器皿基礎收服率上。
- **星球 BOSS**：小行星／衛星／行星／超巨星的 BOSS 分別視為幼年／少年／成年／超載。基本器皿階 ≥ BOSS 階時必定收服（100%）。
- **進階器皿**依十屬性製作。在同屬性進階地形／地城內使用時加上該器皿的地形加成；在同屬性地城內對**同屬性地城 BOSS** 必定收服（100%）。進階器皿不套用階差加減。
- 其餘加成（豐饒詞綴 +10、生活能力、料理）照舊相加，結果限制在 0–100%。

## 進度保存
圖鑑內容結構與「未知 → 基本 → 完整」解鎖規則見 [角色、宙獸與技能圖鑑](encyclopedia.md)。

- 單機存檔：大廳狀態（持有宙獸、圖鑑、資源）。星球中途**不存檔**（roguelite 一場到底，Q-M4）：中途離開＝放棄本場，已收服的宙獸帶回大廳。

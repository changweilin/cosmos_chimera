# 大廳與 Meta 循環

## 循環
```
地球大廳 ──選星──▶ 生成星球(seed) ──▶ 探索/任務/BOSS ──▶ 收服/得蛋 ──▶ 返回地球
   ▲                                                                   │
   └──────────── 孵蛋、進化、隊伍編成、圖鑑更新 ◀───────────────────────┘
```

## 地球大廳
- 位置：地球上的觀測站（夜空開闊處）。玩家仰望星海，星座即星球類型；選擇後顯示：尺寸、主屬性、詞綴預覽、推薦等級。
- 每次選擇都**隨機生成一顆新星球**（新 seed）。允許輸入／分享 seed 重玩同一顆星球（Q-M1）；因 BOSS 階段依玩家等級抽，分享時連同階段一起分享。
- 大廳功能：隊伍編成（6 主力 / 副手配置）、圖鑑、招式表、特性表、關係表、孵蛋所、多人房間。

## 收服與蛋
- 完成任務或擊敗 BOSS → 取得「收服機會」或「蛋」。
- 野外一般宙獸可收服：擊倒後投擲收服道具（Q-M2）。
- 蛋孵化條件（場數？時間？）→ Q-M3。

## 收服道具
三個類別，玩家投擲道具收服宙獸；收服時使用的類別記錄在**該隻個體**上（存檔欄位 `vessel`，不是物種資料）。

| 類別 | ID | 作為主力 | 作為副手提供給主力 |
|---|---|---|---|
| 符籙卡片 | `talisman_card` | 無差別 | 一個招式 |
| 琉璃珠 | `glass_bead` | 無差別 | 特性 |
| 魔術方塊 | `magic_cube` | 無差別 | 解鎖主力自己的超載（見 `creatures.md#超載`） |

- 每隻副手只提供**一項**，由類別決定，不再由玩家二選一。
- 後期可消耗素材把個體轉換到另一個類別。解鎖時機、素材種類與數量、蛋孵化的宙獸屬於哪一類 → Q-C13。
- 三類道具的投擲動作、收服特效各自不同（美術規格見 `art-asset-pipeline.md`）。

## 進度保存
- 單機存檔：大廳狀態（持有宙獸、圖鑑、資源）。星球中途**不存檔**（roguelite 一場到底，Q-M4）：中途離開＝放棄本場，已收服的宙獸帶回大廳。

# 大廳與 Meta 循環

## 循環
```
地球大廳 ──選星──▶ 生成星球(seed) ──▶ 探索/任務/BOSS ──▶ 收服/得蛋 ──▶ 返回地球
   ▲                                                                   │
   └──────────── 孵蛋、進化、隊伍編成、圖鑑更新 ◀───────────────────────┘
```

## 地球大廳
- 位置：地球上的觀測站（夜空開闊處）。玩家仰望星海，星座即星球類型；選擇後顯示：尺寸、主屬性、詞綴預覽、推薦等級。
- 每次選擇都**隨機生成一顆新星球**（新 seed）。是否允許重玩同一 seed（分享 seed 給朋友）→ Q-M1。
- 大廳功能：隊伍編成（6 主力 / 副手配置）、圖鑑、招式表、特性表、關係表、孵蛋所、多人房間。

## 收服與蛋
- 完成任務或擊敗 BOSS → 取得「收服機會」或「蛋」。
- 野外是否也能收服一般宙獸（阿爾宙斯式）→ Q-M2。
- 蛋孵化條件（場數？時間？）→ Q-M3。

## 進度保存
- 單機存檔：大廳狀態（持有宙獸、圖鑑、資源）。星球中途存檔 → Q-M4（roguelite 式不存 vs. 可中斷）。

# 大廳與 Meta 循環

## 循環
```
地球大廳 ──選星──▶ 生成星球(seed) ──▶ 探索/任務/BOSS ──▶ 收服/得蛋 ──▶ 返回地球
   ▲                                                                   │
   └──────────── 孵蛋、進化、隊伍編成、圖鑑更新 ◀───────────────────────┘
```

## 地球大廳（母星球：固定單機主世界與行星生態）
- **雙天體母星—衛星系統**：
  - **母星球（地球大廳，`LobbyPlanet`）**：實際可自由探索的固定單機主世界行星（半徑 `R = 2560 m`＝超巨星的 2 倍，圓周 `16.1 km`，表面積 `82.4 km²`；固定種子 `LobbyPlanet.Seed`）。
  - **搖籃星（`cradle_planet`，`R = 320 m`）**：**母星球的天然衛星（月亮）**，同時也是玩家與好友的故鄉與新手任務舞台。受母星球磁層庇護，天氣固定晴朗；完成 4 號小鎮「候鳥歸途」主線後可跨天體傳送返鄉。
- **行星氣候學、地質學與海洋水文學（母星球全 24 地貌分布原則）**：
  - **行星氣候帶（依球面緯度 `|y|` 與高地／林線）**：
    - **赤道與副熱帶（`|y| < 0.30`～`0.45`）**：東岸信風迎風面為溼潤河谷（`river_valley`）、沼澤（`swamp`）、熱帶森林（`forest`）與進階雨林；背風雨影與副熱帶高壓下沉帶形成沙漠（`desert`）、砂岩峽谷（`canyon`）、花崗岩圓丘（`granite_domes`）與張裂谷（`rift_valley`），常發高溫／沙塵暴與塵捲風。
    - **中緯度溫帶西風帶（`|y| ∈ [0.30, 0.70]`）**：鋒面氣旋與地形雨交會，配置草原（`grassland`）、溫帶闊葉／混合林、台地（`plateau`）、板岩斷崖（`slate_cliffs`）、喀斯特（`karst`）與岩洞外圍（`cavern_outer`），高空盛行西風急流（候鳥遷徙走廊）。
    - **高緯寒帶與極區環流（`|y| > 0.70` 與林線 `≥ 0.026 R` 以上）**：極地冰河作用配置 **5 種寒帶地貌**——凍原（`tundra`）、冰川 U 谷（`glacier`）、冰斗（`cirque`）、冰磧丘陵（`moraine`）、冰原（`ice_field`）與峽灣（`fjord`）；極圈邊緣受衛星潮汐共振分化出永晝海岸（`eternal_day`）與永夜斷崖（`eternal_night`）。
  - **板塊地質與礦脈帶**：分為①熱點／張裂玄武岩火山帶（鐵、煤、油頁岩、地震噴發）②造山帶與侵入岩體（銅／鐵／金／銀、十屬性晶洞）③碳酸鹽喀斯特溶蝕帶（銀／銅／金、洞穴菌菇）④冰河刨蝕與沖積帶（冰斗銀礦、冰磧砂金）。
  - **海洋水文與漁場**：赤道淺海群島（`archipelago`，水深 `≤ 1 m` 淺灘供初期涉水與岸釣）→ 溫帶河口與高緯峽灣交會處形成冷暖湧升流漁場（`river_valley` ↔ `fjord`，盛產食物主線生鱸魚與極地結冰環境）→ 隱沒帶海溝深海盆地（水深 `> 1 m`，對應深海關主與海底資源）。
- **母星球 8 座聚落、守關對戰與一週目主線動線**：
  - 星球固定配置 **8 座主要陸地城鎮**——**3 小鎮 (`Town`)、2 部落 (`Tribe`)、2 城市 (`City`)、1 城邦 (`CityState`)**（基於聚落地理學，極區不設大型城邦，8 號設為部落、5 號設為大城邦），由主路／小徑／橋樑貫通。

- **進階地形軟性難度門檻（Soft Gating）**：玩家可隨時自由探索母星球任何地帶，但尚未獲得該關主接任務資格或未攜帶對應 `immune_*` 生活技時，進階地形周邊與內部會施加強烈環境懲罰（如火山過熱燒傷、冰冠過冷凍傷、深海高壓、高塔落雷感電、永夜侵蝕與聖光致盲）與高階敵對護衛（詳見 [planet-world.md#進階地形軟性環境危害](planet-world.md#進階地形軟性環境危害)）。
- **探索與大廳功能**：母星球上可自由走訪城鎮與全地形、採集素材、與野外野生宙獸戰鬥及收服（無星球 BOSS）；隨時可開啟大廳選單進行隊伍編成（6 主力 / 副手配置）、進化、裝備紙娃娃、圖鑑、主動技表、被動技表、關係表、孵蛋所、**星海選星**與**主線劇情**。
- **星海選星（元素素材門檻＋主線解鎖尺寸）**：
  - 每次選擇隨機世界都**隨機生成一顆新星球**（新 seed），並**消耗該星球主屬性的元素素材**（小行星 1、矮行星 2、行星 4、超巨星 6）。允許輸入／分享 seed 重玩同一顆星球（Q-M1）；因 BOSS 階段依玩家等級／解鎖階段抽，分享時連同階段一起分享。
  - **星球尺寸隨主線劇情逐步解鎖**：初始僅開放基礎**小行星 (`Asteroid`, R = 320 m)**（完成新手任務）；2 號部落**完成食物系列主線**後解鎖**矮行星 (`Moon`, R = 640 m)**；完成 **3 號五關主＋4 號候鳥歸途**後解鎖**行星 (`Planet`, R = 960 m)**；完成 **8 號部落一週目（十關主＋宿敵任務）**後解鎖**超巨星 (`Supergiant`, R = 1280 m)**（`StarSelectRules` 亦支援對既有試煉計數舊介面相容）。

## 收服與蛋
- 完成任務或擊敗 BOSS → 取得「收服機會」或「蛋」。
- 野外一般宙獸可收服：擊倒後投擲收服道具（Q-M2）。
- 蛋孵化條件（Q-M3 定案）：放入**孵化場**後累積進度——步行距離（超巨星繞一圈 = 100%）、戰鬥次數（1 次 = 2%）、戰勝 BOSS（+10%）。

## 收服道具
三個類別，玩家投擲道具收服宙獸；收服時使用的類別記錄在**該隻個體**上（存檔欄位 `vessel`，不是物種資料）。

| 類別 | ID | 作為主力 | 作為副手提供給主力 |
|---|---|---|---|
| 符籙卡片 | `talisman_card` | 無差別 | 一個主動技 |
| 琉璃珠 | `glass_bead` | 無差別 | 被動技 |
| 魔術方塊 | `magic_cube` | 無差別 | 解鎖主力自己的超載（見 `creatures.md#超載`），並提供副手物種的元素／抗性加成（`crafting.md#魔術方塊副手`） |

- 每隻副手只提供**一項**，由類別決定，不再由玩家二選一。
- 後期轉換類別（Q-C13 定案）：於**矮行星劇情完成後**由特定主動技／被動技解鎖（部分主動技／被動技兼具生活用途與進入特殊地形能力），消耗專精屬性素材；更換時**只更換功能，不更換外觀**（外觀維持收服／孵化時的原始器皿）。**蛋孵化的宙獸承襲親代類別**。
- 三類道具的投擲動作、收服特效各自不同（美術規格見 `art-asset-pipeline.md`）。

### 收服器皿分階
類別（上表）決定副手提供什麼；收服率另由器皿的**階**決定。**兩者並存**：每個基本器皿同時具備類別與階（例如「成年階琉璃珠」）；**進階（十屬性）器皿依屬性對應類別**。

- **基本器皿**分四階：幼年／少年／成年／超載。對野生宙獸，器皿階每高於目標型態一階 **+15** 個百分點、每低一階 **−25** 個百分點，加在器皿基礎收服率上。
- **星球 BOSS**：小行星／衛星／行星／超巨星的 BOSS 分別視為幼年／少年／成年／超載。基本器皿階 ≥ BOSS 階時必定收服（100%）。
- **進階器皿**依十屬性製作。在同屬性進階地形／地城內使用時加上該器皿的地形加成；在同屬性地城內對**同屬性地城 BOSS** 必定收服（100%）。進階器皿不套用階差加減。
- 其餘加成（豐饒詞綴 +10、生活能力、料理）照舊相加，結果限制在 0–100%。

# 遊戲 UI 設計規格

本文件定義《宙獸紀 · COSMIMERA》遊戲內主畫面、選單編排、任務提示與角色互動 UI 現行規格（手把／鍵鼠按鍵綁定來源見 [controls.md](controls.md)，效能與平台規格見 [vision.md](vision.md)）。

## 1. 視覺分區與參考原則

- **遊戲內主畫面 HUD（參考《薩爾達傳說：曠野之息》）**：
  - **低干擾高透明**：透明暗墨襯底（`rgba(16, 20, 26, 0.72–0.84)`）搭配古銅金細邊框（`1px`）與象牙白正文，保留中央視野與星球地平線。
  - **7 吋螢幕可讀性**：Steam Deck 800p 下，HUD 正文 ≥ `13–14px`、角色對話正文 `16px`、按鍵鍵帽標記粗體高對比。
- **選單、任務與敘事互動（參考《寶可夢傳說：阿爾宙斯》）**：
  - **和紙書卷選單**：冒險手冊採用暖和紙底色配深墨褐字體、書籤式頂部分頁與靛青／朱紅印章重點，底部固定操作提示列。
  - **簡潔敘事引導**：左上角任務卡拆為類型標籤、標題目標、獨立羅盤膠囊與地區氣候副列；底部置中對話框搭配凸出說話者名牌。

## 2. 六大元件規格

| 元件 | 參考風格 | 版面位置 | 結構與行為 |
|---|---|---|---|
| **主畫面 HUD** | 曠野之息 | 螢幕四角（中央留空） | 左上：任務卡＋玩家精簡 HP／翻滾槽；頂中：BOSS 血條（含 `66%` / `33%` 狂暴刻度線）與操作教學橫幅；右上：手冊按鈕＋隊伍 6 格狀態列（主力亮框，備援低對比）；底部：情境按鍵列。 |

| **角色與近身互動** | 阿爾宙斯 | 底部置中對話框／中下氣泡 | 好友／宿敵語句於底部置中對話框顯示（左上獨立說話者名牌＋正文＋右下 `▼` 推進符號），不打斷戰鬥測試流程；近身野生互動維持雙段提示氣泡（鍵帽＋目標動作）與 4 選項墨金互動選單。 |

## 3. 實作與技術邊界

- **UI 框架**：全數以 Unity UI Toolkit 實作於 `Assets/_Project/Bootstrap/Resources/UI/`（`CosmimeraTheme.uss`、`GameHud.*`、`AdventureHandbook.*`）與 `Assets/_Project/Bootstrap/Demo/UI/`。
- **熱路徑零配置**：`RunSession.Hud.cs`（`LateUpdate`）與 `GameHudView.cs` 透過狀態欄位進行 dirty check，並以預先配置 buffer 與 `VisualElement` pool 更新按鍵列、教學鍵帽與隊伍卡片；禁止每幀 `Clear()` 重建或產生 LINQ / 字串配置。
- **USS 相容規範**：嚴格禁用 UI Toolkit 不支援的屬性（`gap`、`box-shadow`、`backdrop-filter`、`linear-gradient`）；動畫 `transition-duration` 定義於基底 class。
- **既有面板相容**：`GameOverlay`（星海選星／結算）沿用 `CosmimeraTheme.uss` 基礎類別維持深色可讀性；`AdventurePanel` 維持原有 C# 建構 API 與元件名稱不變。

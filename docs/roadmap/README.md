## 現在（2026-11-15）
D0 已可完整跑一場（EditMode 2114/2114、PlayMode 129/129）；瓶頸是**人工試玩**與待決問題，不是實作量。

1. **人工試玩** `Bootstrap/Demo.unity`（流程見 `../demo-runbook.md`）：小行星 R=320、海岸 BOSS、程序化地貌、道路與聚落外觀（P3-11 表現層剛接上，未經目視）、遊蕩與推擠手感、樹／岩石／建築被招式打壞與阻擋宙獸（P3-12 規則層剛接上，掉落尚未可拾取）。**場景美術（草、海面、天空與雲、陰影，P1-07／08／09；只看過 verdant／lava／ice 白天）**：黃昏與夜晚的天色、其餘三種星球、草在 Steam Deck 的幀率。**場景物件（程序化樹／岩／晶簇網格與 `ToonScenery`，只在測試台截圖看過）**：星球實景的造型與配色、樹冠風擺、晶體夜間發光、打壞與滾動時的外觀。**聚落建築與橋（P3-11 表現層，程序化網格 `ArchitectureMeshes`，只在測試台截圖看過：`d0-shot-arch-*.png`，街景 `d0-shot-arch-street-*.png`）**：六種星球 × 八個時代（時代由 seed 抽）＋主／副風格混合在實景是否協調、同一聚落內造型／新舊／毀損的差異是否夠明顯又不雜亂、未來時代造型是否太素、屋簷會不會擋住攝影機、夜間門燈／亮窗／符文柱亮度、斜坡上的基座、橋體與海面及岸邊的接合、建築被打壞時的外觀。**地表地牢（P3-13，未經目視）**：區域牆是否擋得住角色（跳躍、衝刺）、隘口寬度與牆的外觀、跟隨的宙獸會不會卡在牆後、BOSS 競技場封印在擊倒菁英後解除、遠景牆的鋸齒。**植被下層（P3-20，灌木／箭竹叢／芒草，未經目視）**：密度是否太密或太疏、箭竹只在高地是否看得出來、芒草花穗風擺、灌木與箭竹擋路的手感、Steam Deck 幀率（90 m 內多約 300 個物件）。**依地貌選種（P3-25，未經目視）**：各地貌的物種組合是否一眼可辨（沙漠仙人掌、沼澤板根樹與蘆葦、峽谷礦脈與石筍、凍原冰柱與冰磧石）、林班邊界（約 60 m）是否太方、人工林行列是否自然、礦脈與寶石晶洞的辨識度與夜間發光、11 個新造型（`Logs/scenery-*.png` 可用 `COSMIMERA_CAPTURE=1` 重拍）、印章外緣物種交錯是否突兀、Steam Deck 幀率。**地質變體（P3-24 a，未經目視）**：同一顆星球不同印章的基岩（喀斯特石林、玄武岩柱、花崗岩圓丘、板岩）是否一眼可辨、地表岩色與散佈岩石是否同色、印章邊緣岩色交界是否突兀、`granite_tor`（最大 5 m）會不會擋路太多。**遠景輪廓（P1-15，只看過測試截圖）**：走動時 90 m 交界處近景物件與遠景輪廓的交接是否看得出跳變、外緣（≤ 260 m）淡出是否自然、晶簇遠景不發光是否突兀、Steam Deck 幀率。**小物件（程序化網格 `PropMeshes`，未經目視）**：破壞碎片、地上素材／寶石／光點的造型與夜間發光、寶藏房寶箱、競技場封印晶簇（是否看得出「被封住」、尖端是否超出碰撞圓柱）。
